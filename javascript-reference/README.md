# JavaScript 키워드 참고서

`index.html`을 브라우저에서 직접 열어 사용한다. 서버, 패키지 설치와 인터넷 연결 없이 검색과 예제가 동작한다. MDN 원문 링크는 인터넷 연결이 필요하다.

67개 항목을 9개 주제로 나눴다.

- 실행과 변수
- 자료형과 연산자
- 조건과 반복
- 함수와 스코프
- 문자열과 배열
- 객체와 데이터
- DOM 선택과 변경
- 이벤트 등록과 제어
- 입력과 브라우저 이벤트

각 항목에는 설명, 문법, 주의점, HTML/CSS와 JavaScript 편집기, 실행 결과, 관련 키워드와 원문 링크가 있다. 예제 안의 버튼과 입력을 직접 조작해 이벤트를 확인한다. console 출력, 실행 오류와 구문 오류는 미리보기 안에 표시된다.

실행은 수정한 코드를 새 미리보기 문서에서 실행한다. 초기화는 원본 코드로 돌아가며 이전 문서의 핸들러와 타이머도 제거한다. 전체 예제 복사는 단독 실행 가능한 HTML 문서를 복사한다. 브라우저가 자동 복사를 제한하면 선택된 전체 코드를 Ctrl+C로 복사할 수 있다. 편집 내용은 원본 파일에 자동 저장되지 않는다.

미리보기는 `sandbox="allow-scripts allow-forms"`인 iframe에서 실행한다. 부모 문서 접근 권한을 주지 않으며 폼 이벤트 예제를 위해 폼 동작을 허용한다. DOM과 이벤트는 브라우저 API이고, 변수와 함수 등의 언어 문법과 구분한다. Promise, 네트워크 요청, 모듈과 저장소 API는 이번 범위에서 제외했다.

## 검증

2026-10-01, Windows Chrome에서 `file://` 방식으로 67개 예제의 로딩과 모바일 360px 화면, 내부 파일 링크를 확인했다. 검색과 주제 필터, 코드 수정과 초기화, 오류 표시, 복사 제한 시 수동 복사와 복사한 HTML의 실행을 확인했다. 클릭, 입력, 폼 검증과 Enter 제출, 키보드와 포커스, 이벤트 전파와 중단, 핸들러 해제, 이벤트 위임, once와 signal 해제, 타이머를 실제 조작해 확인했다. JavaScript를 비활성화해도 목차, 설명과 예제 원문은 읽을 수 있다.

## 구성

`entries/`는 개별 키워드의 정적 HTML 파일이다. 설명과 예제 원문은 해당 파일에서 수정한다. `assets/reference.js`는 검색과 편집기 실행을 담당하고 `assets/reference.css`는 공통 화면 스타일을 담당한다. 예제는 부모 참고서의 JavaScript 상태를 공유하지 않는다.
