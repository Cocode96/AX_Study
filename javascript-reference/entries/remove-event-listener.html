이벤트 등록과 제어

removeEventListener

등록한 이벤트 핸들러를 해제한다.

문법과 사용

target.removeEventListener("click", handler, capture)

등록 때와 같은 함수 객체와 같은 capture 값이 필요하다. 겉모양이 같은 새 화살표 함수는 다른 객체다. once/passive 옵션은 제거 매칭 조건이 아니다.

수정하고 실행

값이나 핸들러를 바꾼 뒤 실행한다. 이벤트 예제는 미리보기 안에서 버튼이나 입력을 조작한다. 실행과 초기화는 새 문서를 만들어 기존 이벤트와 타이머도 제거한다. 수정 코드는 파일에 자동 저장되지 않는다.

안 될 때 확인

  • ReferenceError는 이름과 스코프, TypeError는 값의 타입이나 null 여부를 확인한다. SyntaxError는 괄호, 따옴표, 연산자와 문법을 확인한다.
  • DOM 요소를 못 찾으면 선택자와 실행 시점을 확인한다. 이벤트 콜백이 즉시 실행되면 함수 전달과 함수 호출을 구분한다.
