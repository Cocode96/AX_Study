게임 클라이언트 프로그래밍 경험을 바탕으로, 게임 개발 과정의 반복 작업과 복잡성을 줄이는 **AX Agent**를 만들기 위해 Python을 학습하는 저장소입니다.

단순 문법 암기보다 Python의 실행 방식과 자료구조를 C++과 비교하며 이해하고, 이후 게임 로그 분석, 자동 QA, 개발 도구 자동화로 확장하는 것을 목표로 합니다.

## 학습 방향

- Python 기초 문법과 실행 환경 이해
- C++과 Python의 자료형, 메모리, 객체 모델 비교
- Jupyter Notebook을 활용한 개념 정리와 실습
- 게임 개발용 AI Agent와 자동화 도구 제작을 위한 기반 구축
