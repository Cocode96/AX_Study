# JavaScript 키워드 참고서

`index.html`을 브라우저로 직접 연다. 설치, 서버와 인터넷 연결 없이 검색과 실행 예제를 사용할 수 있다. MDN 원문 링크와 실제 서버 API 호출에는 인터넷 또는 해당 서버 연결이 필요하다.

76개 키워드, 10개 주제, 152개 기본/비교 예제로 구성했다. JavaScript 문법, DOM, 이벤트와 AJAX를 다룬다. 각 항목에는 사용 맥락, 문법, 입력과 반환값, 원본 변경 여부, 해당 항목의 주의점, 기대 결과와 MDN 원문 링크가 있다.

## 사용

목차에서 영문 키워드와 한글 개념으로 검색한다. `/` 키는 검색창에 포커스를 주고, 검색창에서 Escape를 누르면 조건을 초기화한다. 검색과 주제 조건은 주소에 반영되어 뒤로 이동하거나 주소를 다시 열어 유지할 수 있다. 일부 브라우저에서 file URL의 주소 변경이 제한되어도 검색은 계속 사용할 수 있다.

상세 페이지에서는 기본 예제와 비교 예제를 선택한다. JavaScript / HTML 탭에서 코드를 수정한 뒤 실행 또는 Ctrl+Enter를 누른다. 수정했지만 아직 실행하지 않은 내용은 상태 표시로 구분한다. 원본으로 초기화는 선택한 예제의 코드와 결과를 초기화하고 기존 타이머와 핸들러도 제거한다. 편집 내용은 파일에 자동 저장되지 않는다.

오른쪽 미리보기에서 버튼, 입력과 폼을 직접 조작한다. console 출력, 경고와 오류를 구분해 표시하고 JavaScript 구문/실행 오류의 행도 표시한다. 출력 지우기는 코드와 이벤트 상태를 유지하고 로그만 지운다. 전체 예제 복사는 별도로 실행할 수 있는 HTML 문서를 복사하며, 권한 제한 시 전체 코드가 선택되어 수동으로 복사할 수 있다.

JavaScript를 꺼도 설명과 두 예제의 원문을 읽을 수 있다. 모바일에서는 코드와 결과가 세로로 배치된다.

## AJAX 예제의 범위

AJAX는 새로고침 없이 응답 데이터를 필요한 DOM에 적용하는 방식이다. Promise, async/await, fetch, 응답 파싱, HTTP 오류, 요청 취소와 최신 결과 처리를 연결해 설명한다.

기본 fetch 예제는 브라우저 내부의 data URL을 읽는다. 실제 외부 서버 요청이 아닌 오프라인 데모다. HTTP 오류 예제는 Response를 직접 만들어 상태 분기를 재현하고, 응답 순서 예제는 타이머로 지연을 재현한다. AJAX 페이지의 서버 연결 코드는 `/api/items`가 JSON 배열을 반환한다고 가정한 참고 코드이며 자동 실행하지 않는다. 실제 API URL과 응답 구조, CORS 정책은 연결할 서버에 맞춰 확인해야 한다.

## 구성과 수정

- `data/catalog.json`: 설명과 두 예제의 원본 데이터
- `tools/build.cjs`: 정적 목차와 개별 HTML 생성
- `entries/`: 생성된 키워드 페이지
- `assets/reference.js`: 검색, 편집기와 격리된 예제 실행
- `assets/reference.css`: 화면 스타일

내용을 수정하려면 catalog를 바꾸고 이 폴더에서 `node tools/build.cjs`를 실행한다. 생성된 HTML을 직접 수정하면 다음 생성 때 덮어쓰므로 내용의 원본은 catalog 한 곳에서 관리한다. Node는 생성할 때만 필요하고 참고서를 읽고 실행할 때는 필요 없다.

미리보기는 `sandbox="allow-scripts allow-forms"` iframe에서 동작하며 부모 문서와 저장소 접근 권한을 주지 않는다. 폼 이벤트 실습을 위해 폼 동작을 허용한다. 별도 서버, 분석 도구와 외부 UI 라이브러리를 사용하지 않는다.

## 검증

2026-10-01, Windows Chrome의 `file://` 방식에서 76개 항목과 152개 기본/비교 예제를 실행했다. 예상치 못한 JavaScript 오류와 외부 네트워크 요청이 없었고 내부 파일 링크와 모바일 360px 화면의 가로 넘침도 없었다. 각 상세 페이지는 360px, 768px와 1440px, 목차는 추가로 320px에서도 확인했다.

검색 조건 복원, 빠른 검색, 편집 탭, 변경 표시, 단축키 실행, 선택 예제 초기화, 출력 지우기와 복사를 확인했다. 이벤트 전파, 핸들러 해제, 동적 위임, 폼 검증과 Enter 제출, 포인터, 스크롤과 타이머를 조작해 검증했다. AJAX 예제는 문서의 timeOrigin과 입력값을 유지하며 목록만 갱신되는지 확인했고 Promise 출력 순서, HTTP 오류 처리, AbortError와 최신 요청 결과 보존도 확인했다. 실제 외부 API 통신은 이 검증에 포함하지 않았다.
