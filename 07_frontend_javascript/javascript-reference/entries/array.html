const original = ['A', 'B'];
const shared = original;
shared.push('C');
const copy = [...original];
copy.push('D');
console.log(original, copy, original === shared);

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

배열을 복사하지 않고 다른 변수에 대입하면 같은 배열을 공유한다. 요소 개수와 마지막 인덱스도 구분한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
