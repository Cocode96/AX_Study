querySelectorAll / NodeList

선택자에 맞는 여러 DOM 요소를 찾는다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

여러 요소를 같은 규칙으로 변경하거나 조사할 때

querySelectorAll의 NodeList는 정적 목록이라 나중에 추가한 요소가 자동 반영되지 않는다. forEach는 가능하지만 map이 필요하면 Array.from이나 전개로 배열로 바꾼다.

먼저 구분할 것

NodeList를 배열처럼 map으로 처리할 수 없다. [...nodes] 또는 Array.from으로 배열로 바꾼다.

비교 예제 원문: 목록은 DOM 추가 후 자동 갱신되지 않는다

HTML / CSS

<ul id="list"><li class="item">기존</li></ul>

JavaScript

// 목록은 DOM 추가 후 자동 갱신되지 않는다
const before = document.querySelectorAll('.item');
const item = document.createElement('li');
item.className = 'item'; item.textContent = '추가';
document.querySelector('#list').append(item);
console.log(before.length, document.querySelectorAll('.item').length);

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

NodeList를 배열처럼 map으로 처리할 수 없다. [...nodes] 또는 Array.from으로 배열로 바꾼다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
