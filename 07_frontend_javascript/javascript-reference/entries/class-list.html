이럴 때 사용한다

UI 활성 상태를 CSS 클래스와 연결할 때

클래스 이름에 .을 붙이지 않는다. toggle(name, boolean)은 상태를 명시적으로 맞춘다. 스타일 규칙은 CSS에 두고 클래스만 바꾸면 관리하기 편하다.

먼저 구분할 것

클래스 이름에 .을 붙이지 않는다. toggle(name,false)는 반드시 제거하고 toggle(name,true)는 반드시 추가한다.

01 / SYNTAX

문법과 값의 흐름

element.classList.toggle("active")
입력 / 조건
클래스 이름, toggle의 선택적인 강제 boolean
결과 / 반환값
contains/toggle은 boolean. add/remove는 undefined
원본 / 상태 변경
요소 class 속성을 변경한다.

기대 결과

클릭마다 활성 상태 true/false와 배경이 바뀐다.

버튼, 입력 등은 오른쪽 미리보기에서 직접 조작한다. 수정 후 실행하거나 Ctrl+Enter를 누른다. 수정 내용은 파일에 자동 저장되지 않는다.

비교 예제 원문: 불리언 상태로 강제 동기화

HTML / CSS

<style>.active{background:#d5f3e8;color:#126349;padding:12px}</style><label><input id="check" type="checkbox"> 활성</label><p id="box">체크 상태와 동기화</p>

JavaScript

// 불리언 상태로 강제 동기화
const box = document.querySelector('#box');
const input = document.querySelector('#check');
input.addEventListener('change', () => {
  box.classList.toggle('active', input.checked);
  console.log(box.classList.contains('active'));
});

기대 결과: 체크하면 true와 녹색 배경, 해제하면 false와 원래 배경

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

클래스 이름에 .을 붙이지 않는다. toggle(name,false)는 반드시 제거하고 toggle(name,true)는 반드시 추가한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
