이럴 때 사용한다

검색 결과나 조건을 통과한 데이터만 남길 때

콜백 결과가 truthy인 요소가 남는다. 객체 요소는 복사가 아니라 같은 객체 참조를 공유한다.

먼저 구분할 것

filter는 값을 변환하지 않는다. 조건에 맞는 값을 바꾸려면 filter 다음에 map을 조합한다.

01 / SYNTAX

문법과 값의 흐름

list.filter(value => value >= 60)
입력 / 조건
조건을 판단할 콜백 (value,index,array)
결과 / 반환값
조건이 truthy인 원래 요소를 담은 새 배열
원본 / 상태 변경
배열은 새로 만들지만 객체 요소는 같은 참조다.

비교 예제 원문: filter 후 map으로 표시값 변환

JavaScript

// filter 후 map으로 표시값 변환
const users = [{ name: 'A', active: true }, { name: 'B', active: false }];
const names = users.filter(user => user.active).map(user => user.name);
console.log(names, users.length);

기대 결과: ["A"] 2

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

filter는 값을 변환하지 않는다. 조건에 맞는 값을 바꾸려면 filter 다음에 map을 조합한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
