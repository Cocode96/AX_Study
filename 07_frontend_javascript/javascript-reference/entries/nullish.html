?? / ?.

null이나 undefined에 기본값을 주고 안전하게 속성에 접근한다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

0이나 빈 문자열을 유지하며 기본값을 주고 중첩 값을 읽을 때

??는 0, false, 빈 문자열을 유지한다. ?.는 null/undefined에서 undefined를 반환하지만 선언하지 않은 변수의 접근까지 막지는 않는다.

먼저 구분할 것

?. 뒤가 없는 경우를 대비해 ??로 화면 기본값까지 정한다. 미선언 식별자 접근 오류까지 해결하지는 않는다.

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

?. 뒤가 없는 경우를 대비해 ??로 화면 기본값까지 정한다. 미선언 식별자 접근 오류까지 해결하지는 않는다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
