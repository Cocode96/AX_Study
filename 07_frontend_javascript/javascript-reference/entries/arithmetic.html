03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

돈처럼 정확한 소수가 필요하면 부동소수점 오차를 고려한다. JS number는 일반적으로 정수 전용 타입과 분리되어 있지 않다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
