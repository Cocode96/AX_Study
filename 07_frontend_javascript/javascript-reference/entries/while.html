조건이 유지되는 동안 반복하고 흐름을 제어한다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

종료 여부를 조건으로 판단하는 반복을 만들 때

break는 반복을 종료하고 continue는 현재 회차의 나머지를 건너뛴다. continue 전에 종료 조건에 필요한 값이 갱신되어야 한다.

먼저 구분할 것

continue 전에 상태 갱신을 놓치면 같은 조건을 무한히 반복할 수 있다. 브라우저 UI를 막지 않도록 종료 조건을 확인한다.

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

continue 전에 상태 갱신을 놓치면 같은 조건을 무한히 반복할 수 있다. 브라우저 UI를 막지 않도록 종료 조건을 확인한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
