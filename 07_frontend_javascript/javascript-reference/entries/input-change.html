브라우저 API

DOM과 이벤트는 브라우저가 제공하는 기능이다.

JavaScript/입력과 브라우저 이벤트

BROWSER API / 59

input / change / value / checked

입력 중 변화와 값 확정을 구분한다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

편집 중 실시간 반영과 확정된 입력을 구분할 때

텍스트 input은 편집할 때 input이, 값 변경 후 포커스를 잃을 때 change가 발생한다. 체크박스는 전환 시 change가 발생한다. JS로 value를 대입하는 것만으로 input 이벤트가 발생하지는 않는다.

먼저 구분할 것

체크박스 동의 상태는 value가 아니라 checked로 읽는다. value는 제출할 값이지 현재 체크 상태가 아니다.

기대 결과

입력 중 input, 다른 곳을 누르면 change, 체크 시 checked: true

버튼, 입력 등은 오른쪽 미리보기에서 직접 조작한다. 수정 후 실행하거나 Ctrl+Enter를 누른다. 수정 내용은 파일에 자동 저장되지 않는다.

비교 예제 원문: value 대입과 이벤트 발생 분리

HTML / CSS

<input id="input" aria-label="입력 값"><button id="set" type="button">value 대입</button><button id="emit" type="button">input 직접 발생</button>

JavaScript

// value 대입과 이벤트 발생 분리
const input = document.querySelector('#input');
input.addEventListener('input', () => console.log('input 이벤트:', input.value));
document.querySelector('#set').addEventListener('click', () => {
  input.value = '자동 입력';
  console.log('대입만 했습니다.');
});
document.querySelector('#emit').addEventListener('click', () => {
  input.dispatchEvent(new Event('input', { bubbles: true }));
});

기대 결과: 대입 버튼은 대입만 출력. 이벤트 버튼을 누르면 input 이벤트: 자동 입력 출력

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

체크박스 동의 상태는 value가 아니라 checked로 읽는다. value는 제출할 값이지 현재 체크 상태가 아니다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
