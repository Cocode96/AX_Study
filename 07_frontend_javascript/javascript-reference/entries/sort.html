숫자 목록이나 객체 목록의 표시 순서를 정할 때

sort와 reverse는 원본을 바꾼다. sort 기본 비교는 문자열 기준이므로 숫자에는 비교 함수를 전달한다. 원본을 보존하려면 얕게 복사한 배열을 정렬한다.

먼저 구분할 것

숫자 정렬에 기본 sort를 쓰면 문자열 순서가 된다. 비교 함수에서 boolean을 반환하지 않는다.

비교 예제 원문: 객체의 숫자 속성으로 정렬

JavaScript

// 객체의 숫자 속성으로 정렬
const users = [{ score: 40 }, { score: 90 }, { score: 60 }];
const sorted = [...users].sort((a, b) => b.score - a.score);
console.log(sorted.map(user => user.score));
console.log(users.map(user => user.score));

기대 결과: [90,60,40] / [40,90,60]

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

숫자 정렬에 기본 sort를 쓰면 문자열 순서가 된다. 비교 함수에서 boolean을 반환하지 않는다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
