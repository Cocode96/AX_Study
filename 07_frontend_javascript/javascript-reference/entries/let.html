03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

같은 블록의 재선언은 SyntaxError다. 다른 블록에서 같은 이름을 선언하면 별도 변수다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
