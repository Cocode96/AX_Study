focus와 blur는 버블링하지 않는다. 부모에서 위임하려면 focusin/focusout 또는 캡처 등록을 쓴다. Tab으로 이동해 키보드 동작도 확인한다.

기대 결과

Tab으로 이동하면 진입/이탈과 input의 name 출력

버튼, 입력 등은 오른쪽 미리보기에서 직접 조작한다. 수정 후 실행하거나 Ctrl+Enter를 누른다. 수정 내용은 파일에 자동 저장되지 않는다.

비교 예제 원문: 캡처로 focus를 부모에서 관찰

HTML / CSS

<form id="form"><label>첫 입력 <input name="first"></label><label>둘째 입력 <input name="second"></label></form>

JavaScript

// 캡처로 focus를 부모에서 관찰
const form = document.querySelector('#form');
form.addEventListener('focus', event => console.log('부모 캡처:', event.target.name), true);
form.addEventListener('focus', () => console.log('부모 버블은 호출 안 됨'));

기대 결과: 각 입력에 포커스를 주면 부모 캡처만 출력한다.

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

부모의 blur 핸들러가 안 불리면 버블링하지 않는 이벤트인지 확인한다. 캡처 등록이면 조상도 관찰할 수 있다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
