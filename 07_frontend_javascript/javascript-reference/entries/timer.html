01 / SYNTAX

문법과 값의 흐름

const id = setInterval(fn, 1000); clearInterval(id);
입력 / 조건
콜백과 밀리초, 해제 함수에는 반환된 타이머 ID
결과 / 반환값
setTimeout은 1회, setInterval은 해제 전까지 반복. 둘 다 ID 반환
원본 / 상태 변경
ID를 보관해 중복 예약과 종료를 관리한다.

버튼, 입력 등은 오른쪽 미리보기에서 직접 조작한다. 수정 후 실행하거나 Ctrl+Enter를 누른다. 수정 내용은 파일에 자동 저장되지 않는다.

비교 예제 원문: 0ms도 동기 코드 뒤에 실행

JavaScript

// 0ms도 동기 코드 뒤에 실행
console.log('1 동기 시작');
setTimeout(() => console.log('3 타이머'), 0);
console.log('2 동기 끝');

기대 결과: 1 동기 시작 → 2 동기 끝 → 3 타이머

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

지연 시간은 정확한 실행 시각이 아니다. 버튼을 여러 번 눌러 중복 타이머를 만드는지, 종료 시 ID를 비우는지 확인한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
