이럴 때 사용한다

동적으로 생기는 여러 버튼을 부모에서 한 번에 처리할 때

버블링을 이용한다. target은 버튼 안의 span일 수 있어 closest로 찾는다. 중첩 UI에서 바깥 요소까지 잘못 찾지 않도록 contains 검사도 한다.

먼저 구분할 것

target이 버튼 내부 span일 수 있다. 버튼만 직접 비교하지 말고 closest로 동작 대상을 찾는다.

기대 결과

추가한 항목과 기존 항목 모두 삭제 가능

버튼, 입력 등은 오른쪽 미리보기에서 직접 조작한다. 수정 후 실행하거나 Ctrl+Enter를 누른다. 수정 내용은 파일에 자동 저장되지 않는다.

비교 예제 원문: 자식 글자를 클릭해도 동작 찾기

HTML / CSS

<ul id="list"><li><button type="button" data-action="select"><span>이 글자를 클릭</span></button></li></ul>

JavaScript

// 자식 글자를 클릭해도 동작 찾기
document.querySelector('#list').addEventListener('click', event => {
  const button = event.target.closest('button[data-action]');
  if (!button || !event.currentTarget.contains(button)) return;
  console.log('실제 클릭:', event.target.tagName);
  console.log('찾은 버튼:', button.dataset.action);
});

기대 결과: span 글자를 클릭하면 실제 클릭: SPAN / 찾은 버튼: select

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

target이 버튼 내부 span일 수 있다. 버튼만 직접 비교하지 말고 closest로 동작 대상을 찾는다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
