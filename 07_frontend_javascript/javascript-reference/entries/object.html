03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

변수 키는 user.key가 아니라 user[key]로 읽는다. 점 표기에서 key는 문자 그대로의 속성 이름이다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
