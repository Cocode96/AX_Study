JavaScript

// 없을 때 반환값 구분
const list = [{ id: 1 }];
const found = list.find(item => item.id === 2);
console.log(found?.id ?? '없음');
console.log(list.findIndex(item => item.id === 2));
console.log(list.includes({ id: 1 }));

기대 결과: 없음 / -1 / false

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

find 결과가 없을 때 속성을 바로 읽으면 오류가 난다. ?. 또는 명시적 검사로 없는 경우를 처리한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
