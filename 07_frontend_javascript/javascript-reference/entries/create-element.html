DOM과 이벤트는 브라우저가 제공하는 기능이다.

JavaScript/DOM 선택과 변경

BROWSER API / 48

createElement / append / remove

새 요소를 생성하고 DOM에 추가하거나 제거한다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

동적으로 목록 항목을 추가하거나 제거할 때

createElement만으로 화면에 나타나지 않는다. DOM에 붙여야 한다. 사용자 입력은 textContent로 넣는다. remove는 해당 요소를 부모에서 떼어낸다.

먼저 구분할 것

같은 노드를 다른 부모에 append하면 복사하지 않고 이동한다. 복제하려면 cloneNode를 사용한다.

01 / SYNTAX

문법과 값의 흐름

const item = document.createElement("li"); list.append(item);
입력 / 조건
태그 이름과 추가할 노드 또는 텍스트
결과 / 반환값
createElement는 새 요소. append/remove는 undefined
원본 / 상태 변경
append는 DOM에 연결하고 remove는 부모에서 떼어낸다.

비교 예제 원문: 같은 노드는 복사가 아니라 이동

HTML / CSS

<h4>첫 목록</h4><ul id="first"></ul><h4>둘째 목록</h4><ul id="second"></ul>

JavaScript

// 같은 노드는 복사가 아니라 이동
const item = document.createElement('li');
item.textContent = '옮길 항목';
document.querySelector('#first').append(item);
document.querySelector('#second').append(item);
console.log('첫 목록:', document.querySelector('#first').children.length);
console.log('둘째 목록:', document.querySelector('#second').children.length);

기대 결과: 첫 목록: 0 / 둘째 목록: 1

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

같은 노드를 다른 부모에 append하면 복사하지 않고 이동한다. 복제하려면 cloneNode를 사용한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
