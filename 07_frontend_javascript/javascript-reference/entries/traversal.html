이럴 때 사용한다

버튼에서 자신이 속한 카드나 부모 항목을 찾을 때

closest는 자기 자신부터 조상까지 검사한다. children은 요소만 포함하고 childNodes는 텍스트 노드도 포함한다. closest가 못 찾으면 null이다.

먼저 구분할 것

closest는 자기 자신도 검사한다. children은 요소만, childNodes는 공백 텍스트 노드도 포함한다.

JavaScript

// closest는 자기 자신도 검사
const card = document.querySelector('.card');
console.log(card.closest('.card') === card);
console.log(card.children.length, card.childNodes.length);

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

closest는 자기 자신도 검사한다. children은 요소만, childNodes는 공백 텍스트 노드도 포함한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
