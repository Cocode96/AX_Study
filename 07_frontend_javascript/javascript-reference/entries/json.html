JSON.stringify / JSON.parse

객체와 JSON 문자열을 서로 변환한다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

객체를 전송 가능한 문자열로 만들거나 JSON을 읽을 때

JSON의 키와 문자열은 큰따옴표를 쓴다. 함수와 undefined 등의 값은 그대로 보존되지 않으며 순환 참조를 직렬화하면 오류가 난다. 임의 객체의 완전한 복사 도구로 쓰지 않는다.

먼저 구분할 것

JSON은 JS 코드가 아니다. 작은따옴표 키나 끝 쉼표는 허용되지 않는다. 함수와 undefined는 완전히 보존되지 않는다.

01 / SYNTAX

문법과 값의 흐름

JSON.stringify(value); JSON.parse(text)
입력 / 조건
stringify에 값, parse에 유효한 JSON 문자열
결과 / 반환값
stringify는 JSON 문자열 또는 undefined, parse는 변환한 JS 값
원본 / 상태 변경
원본을 변경하지 않고 파싱 시 새 값을 만든다.

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

JSON은 JS 코드가 아니다. 작은따옴표 키나 끝 쉼표는 허용되지 않는다. 함수와 undefined는 완전히 보존되지 않는다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
