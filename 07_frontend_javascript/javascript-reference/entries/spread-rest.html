03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

중첩 객체가 그대로 공유되는 얕은 복사다. 변경할 경로의 내부 객체도 새로 만들어야 원본을 보존할 수 있다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
