BROWSER API / 51

removeEventListener

등록한 이벤트 핸들러를 해제한다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

UI 종료나 상태 전환 시 더 이상 필요 없는 반응을 끊을 때

등록 때와 같은 함수 객체와 같은 capture 값이 필요하다. 겉모양이 같은 새 화살표 함수는 다른 객체다. once/passive 옵션은 제거 매칭 조건이 아니다.

먼저 구분할 것

remove에 새로운 화살표 함수를 쓰면 등록했던 함수와 달라 해제되지 않는다. 함수 참조를 저장해 재사용한다.

01 / SYNTAX

문법과 값의 흐름

target.removeEventListener("click", handler, capture)
입력 / 조건
등록 때의 이벤트 이름, 같은 함수 객체와 같은 capture
결과 / 반환값
반환값은 undefined. 일치하는 핸들러를 제거한다.
원본 / 상태 변경
대상의 이벤트 리스너 목록을 변경한다.

실행 결과

기대 결과

실행은 출력, 핸들러 해제 뒤 실행은 추가 출력 없음

버튼, 입력 등은 오른쪽 미리보기에서 직접 조작한다. 수정 후 실행하거나 Ctrl+Enter를 누른다. 수정 내용은 파일에 자동 저장되지 않는다.

비교 예제 원문: capture 값도 맞춰서 제거

HTML / CSS

<button id="button" type="button">실행</button><button id="remove" type="button">같은 capture로 해제</button>

JavaScript

// capture 값도 맞춰서 제거
const button = document.querySelector('#button');
function handle() { console.log('capture 핸들러'); }
button.addEventListener('click', handle, true);
button.removeEventListener('click', handle, false); // 매칭되지 않음
document.querySelector('#remove').addEventListener('click', () => {
  button.removeEventListener('click', handle, true);
  console.log('올바르게 해제');
});

기대 결과: 해제 전에는 capture 핸들러 출력, 올바르게 해제한 뒤에는 출력 없음

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

remove에 새로운 화살표 함수를 쓰면 등록했던 함수와 달라 해제되지 않는다. 함수 참조를 저장해 재사용한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
