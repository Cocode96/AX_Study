async / await

Promise 완료를 기다리는 코드를 순서대로 읽기 쉽게 표현한다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

비동기 단계에 try/catch와 순차 처리 흐름을 적용할 때

async 함수는 항상 Promise를 반환한다. await는 해당 async 함수의 후속 실행을 기다리게 하며 브라우저 전체를 멈추지 않는다. 일반 스크립트 최상위에는 await를 바로 쓸 수 없다.

먼저 구분할 것

async 함수 호출 결과를 일반 값으로 바로 읽지 않는다. await 또는 then으로 결과를 받는다.

JavaScript

// async 함수의 반환값 확인
async function getValue() { return 42; }
const result = getValue();
console.log(result instanceof Promise);
result.then(value => console.log('받은 값:', value));

기대 결과: true → 받은 값: 42

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

async 함수 호출 결과를 일반 값으로 바로 읽지 않는다. await 또는 then으로 결과를 받는다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
