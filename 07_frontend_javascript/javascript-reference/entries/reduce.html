reduce

배열을 누적해 하나의 결과로 만든다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

총합이나 그룹별 집계처럼 누적 결과가 필요할 때

초깃값을 생략하면 첫 요소가 누적값이 되고 빈 배열에서는 오류가 난다. 초깃값을 명시하면 결과 타입과 빈 배열 동작이 분명해진다.

먼저 구분할 것

빈 배열에서 초기값 없는 reduce는 TypeError다. 각 콜백이 다음 누적값을 반환해야 한다.

01 / SYNTAX

문법과 값의 흐름

list.reduce((acc, value) => acc + value, 0)
입력 / 조건
콜백 (accumulator,value,index,array)과 초기값
결과 / 반환값
마지막 누적값. 초기값이 있으면 빈 배열에도 그 값을 반환한다.
원본 / 상태 변경
콜백이 원본을 수정하지 않으면 보존한다.

비교 예제 원문: 집계 결과를 객체로 만들기

JavaScript

// 집계 결과를 객체로 만들기
const counts = ['JS', 'CSS', 'JS'].reduce((acc, value) => {
  acc[value] = (acc[value] ?? 0) + 1;
  return acc;
}, {});
console.log(counts);

기대 결과: {"JS":2,"CSS":1}

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

빈 배열에서 초기값 없는 reduce는 TypeError다. 각 콜백이 다음 누적값을 반환해야 한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
