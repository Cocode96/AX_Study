비교 예제 원문: break를 빼면 이어서 실행

JavaScript

// break를 빼면 이어서 실행
const value = 1;
switch (value) {
  case 1: console.log('첫 case'); // 일부러 break 생략
  case 2: console.log('다음 case도 실행'); break;
  default: console.log('기본 case');
}

기대 결과: 첫 case → 다음 case도 실행

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

case 값은 엄격하게 비교한다. 문자열 "1"과 숫자 1은 다른 분기로 처리된다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
