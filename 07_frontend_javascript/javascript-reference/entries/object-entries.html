Object.keys / values / entries

객체 자신의 열거 가능한 문자열 키와 값을 배열로 얻는다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

객체 속성을 목록으로 표시하거나 반복할 때

entries는 [키, 값] 쌍의 배열이다. Symbol 키와 상속 속성은 이 메서드들의 결과에 포함되지 않는다.

먼저 구분할 것

상속된 속성과 Symbol 키는 결과에 포함되지 않는다. entries를 구조 분해하면 반복 코드를 간단히 만들 수 있다.

01 / SYNTAX

문법과 값의 흐름

Object.keys(obj); Object.values(obj); Object.entries(obj)
입력 / 조건
자신의 열거 가능한 문자열 속성을 가진 객체
결과 / 반환값
keys는 키 배열, values는 값 배열, entries는 [키,값] 배열
원본 / 상태 변경
입력 객체를 변경하지 않는다.

비교 예제 원문: 상속 속성은 entries에 안 나온다

JavaScript

// 상속 속성은 entries에 안 나온다
const base = { inherited: 1 };
const own = Object.create(base);
own.name = 'A';
console.log(Object.keys(own));
for (const key in own) console.log('for...in:', key);

기대 결과: keys는 name만, for...in에는 name과 inherited가 나온다.

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

상속된 속성과 Symbol 키는 결과에 포함되지 않는다. entries를 구조 분해하면 반복 코드를 간단히 만들 수 있다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
