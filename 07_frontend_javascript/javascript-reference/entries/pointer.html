입력과 브라우저 이벤트

pointerdown / pointermove / pointerup

마우스, 펜, 터치 입력을 하나의 이벤트 계열로 처리한다.

문법과 사용

event.pointerId; event.pointerType; event.clientX; event.clientY

clientX/Y는 뷰포트 좌표다. 요소 내부 좌표는 getBoundingClientRect 기준으로 뺀다. 드래그에는 pointer capture와 pointercancel도 고려한다. touch-action은 브라우저 제스처 처리에 영향을 준다.

수정하고 실행

값이나 핸들러를 바꾼 뒤 실행한다. 이벤트 예제는 미리보기 안에서 버튼이나 입력을 조작한다. 실행과 초기화는 새 문서를 만들어 기존 이벤트와 타이머도 제거한다. 수정 코드는 파일에 자동 저장되지 않는다.

안 될 때 확인

  • ReferenceError는 이름과 스코프, TypeError는 값의 타입이나 null 여부를 확인한다. SyntaxError는 괄호, 따옴표, 연산자와 문법을 확인한다.
  • DOM 요소를 못 찾으면 선택자와 실행 시점을 확인한다. 이벤트 콜백이 즉시 실행되면 함수 전달과 함수 호출을 구분한다.
