브라우저 API

DOM과 이벤트는 브라우저가 제공하는 기능이다.

JavaScript/입력과 브라우저 이벤트

BROWSER API / 63

pointerdown / pointermove / pointerup

마우스, 펜, 터치 입력을 하나의 이벤트 계열로 처리한다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

마우스, 터치와 펜의 누름과 이동을 공통으로 처리할 때

clientX/Y는 뷰포트 좌표다. 요소 내부 좌표는 getBoundingClientRect 기준으로 뺀다. 드래그에는 pointer capture와 pointercancel도 고려한다. touch-action은 브라우저 제스처 처리에 영향을 준다.

먼저 구분할 것

drag 중 pointerup만 기다리면 취소 상황을 놓친다. pointercancel과 lostpointercapture도 상태 정리에 활용한다.

pointerdown/move/up/cancel로 입력의 흐름을 받는다.

영역을 누른 채 이동하면 내부 x/y 갱신, 놓으면 놓음 출력

버튼, 입력 등은 오른쪽 미리보기에서 직접 조작한다. 수정 후 실행하거나 Ctrl+Enter를 누른다. 수정 내용은 파일에 자동 저장되지 않는다.

비교 예제 원문: 포인터 종료 상태 정리

HTML / CSS

<div id="area" style="height:130px;padding:20px;background:#d7f3e9;touch-action:none">누른 뒤 영역 밖에서 놓아도 종료</div>

JavaScript

// 포인터 종료 상태 정리
const area = document.querySelector('#area');
let dragging = false;
area.addEventListener('pointerdown', event => {
  dragging = true; area.setPointerCapture(event.pointerId);
  console.log('드래그 시작');
});
function finish(event) {
  if (!dragging) return;
  dragging = false; console.log('드래그 종료:', event.type);
}
area.addEventListener('pointerup', finish);
area.addEventListener('pointercancel', finish);
area.addEventListener('lostpointercapture', finish);

기대 결과: 드래그 시작 → 영역 밖에서 놓아도 드래그 종료: pointerup

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

drag 중 pointerup만 기다리면 취소 상황을 놓친다. pointercancel과 lostpointercapture도 상태 정리에 활용한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
