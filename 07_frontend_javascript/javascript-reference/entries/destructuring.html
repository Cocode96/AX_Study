JavaScript

// undefined와 null의 기본값
const { a = 10, b = 10 } = { a: undefined, b: null };
console.log(a, b);
console.log(b ?? 10);
const { name: displayName } = { name: '손님' };
console.log(displayName);

기대 결과: 10 null → 10 → 손님

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

기본값은 undefined에만 적용된다. null도 기본값으로 바꾸려면 ??를 따로 사용한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
