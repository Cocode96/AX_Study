콜백 함수

다른 함수에 함수를 전달해 필요한 시점에 호출하게 한다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

배열 처리나 이벤트 발생 시 수행할 동작을 전달할 때

handler는 함수를 전달하고 handler()는 지금 호출한 결과를 전달한다. 콜백이라고 항상 비동기인 것은 아니다. 배열 map은 동기적으로 호출한다.

먼저 구분할 것

handler()를 전달하면 지금 실행한 반환값이 전달된다. 함수를 나중에 실행하려면 handler를 전달한다.

비교 예제 원문: 함수 전달과 즉시 호출

JavaScript

// 함수 전달과 즉시 호출
function handler() { console.log('handler 호출'); return 7; }
function inspect(value) { console.log('받은 타입:', typeof value); }
inspect(handler); // 함수를 전달
inspect(handler()); // 실행 결과인 숫자를 전달

기대 결과: 받은 타입: function → handler 호출 → 받은 타입: number

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

handler()를 전달하면 지금 실행한 반환값이 전달된다. 함수를 나중에 실행하려면 handler를 전달한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
