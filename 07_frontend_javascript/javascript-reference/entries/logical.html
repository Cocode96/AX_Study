여러 조건을 조합하거나 조건에 따라 평가를 멈출 때

&&와 ||는 항상 boolean을 반환하지 않는다. 평가를 멈춘 피연산자 값을 반환한다. falsy에는 0, 빈 문자열, null, undefined, NaN, false 등이 있다.

먼저 구분할 것

기본값 선택에서 0과 빈 문자열을 보존해야 하면 || 대신 ??가 맞는지 판단한다.

비교 예제 원문: 단락 평가로 호출을 건너뛴다

JavaScript

// 단락 평가로 호출을 건너뛴다
function mark() { console.log('함수 호출'); return '결과'; }
console.log(false && mark()); // mark를 호출하지 않는다.
console.log(true || mark()); // mark를 호출하지 않는다.
console.log(true && mark());

기대 결과: false → true → 함수 호출 → 결과

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

기본값 선택에서 0과 빈 문자열을 보존해야 하면 || 대신 ??가 맞는지 판단한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
