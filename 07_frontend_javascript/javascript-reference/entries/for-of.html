for...of / for...in

값 순회와 열거 가능한 속성 키 순회를 구분한다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

배열의 값이나 객체의 키-값 쌍을 순회할 때

for...of는 배열과 문자열 같은 iterable의 값을 순회한다. for...in은 상속된 열거 가능 속성도 포함한다. 일반 객체는 Object.entries와 함께 순회하면 편하다.

먼저 구분할 것

일반 객체에 for...of를 바로 쓰면 iterable이 아니라 TypeError다. Object.entries를 사용한다.

01 / SYNTAX

문법과 값의 흐름

for (const value of array) { ... }
입력 / 조건
iterable 값 또는 Object.entries로 변환한 객체
결과 / 반환값
for...of는 값을, for...in은 열거 가능한 문자열 키를 순회한다.
원본 / 상태 변경
순회만으로 원본을 바꾸지 않는다.

비교 예제 원문: 키와 값의 차이

JavaScript

// 키와 값의 차이
const list = ['A', 'B'];
for (const key in list) console.log('in:', key, typeof key);
for (const value of list) console.log('of:', value);
for (const [key, value] of Object.entries({ level: 2 })) console.log(key, value);

기대 결과: in: 0 string / in: 1 string / of: A / of: B / level 2

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

일반 객체에 for...of를 바로 쓰면 iterable이 아니라 TypeError다. Object.entries를 사용한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
