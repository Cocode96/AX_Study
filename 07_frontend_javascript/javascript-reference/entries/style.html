브라우저 API

DOM과 이벤트는 브라우저가 제공하는 기능이다.

JavaScript/DOM 선택과 변경

BROWSER API / 46

style / getComputedStyle

인라인 스타일을 변경하고 계산된 스타일을 읽는다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

짧은 동적 스타일을 적용하거나 실제 계산된 값을 확인할 때

JS 속성명은 background-color가 아니라 backgroundColor처럼 적는다. style은 인라인 값이고 getComputedStyle은 CSS 규칙까지 적용된 계산 결과다.

먼저 구분할 것

CSS 파일의 값은 element.style에서 빈 문자열로 보일 수 있다. 실제 적용값을 알고 싶으면 getComputedStyle을 쓴다.

01 / SYNTAX

문법과 값의 흐름

element.style.backgroundColor = "gold"; getComputedStyle(element).color
입력 / 조건
style 속성 또는 getComputedStyle에 요소
결과 / 반환값
style은 인라인 선언, getComputedStyle은 계산된 CSS 값
원본 / 상태 변경
style 대입은 인라인 스타일을 변경한다.

HTML / CSS

<style>#box{color:rgb(20,100,80)}</style><p id="box">CSS 규칙에서 정한 색상</p>

JavaScript

// 인라인 값과 계산값 비교
const box = document.querySelector('#box');
console.log('인라인:', JSON.stringify(box.style.color));
console.log('계산값:', getComputedStyle(box).color);

기대 결과: 인라인: "" / 계산값: rgb(20, 100, 80)

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

CSS 파일의 값은 element.style에서 빈 문자열로 보일 수 있다. 실제 적용값을 알고 싶으면 getComputedStyle을 쓴다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
