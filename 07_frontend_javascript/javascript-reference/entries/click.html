BROWSER API / 58

click / dblclick

포인터나 키보드로 버튼을 활성화할 때 동작한다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

네이티브 버튼의 포인터와 키보드 활성화를 처리할 때

네이티브 button의 click은 Enter/Space 활성화도 처리한다. dblclick은 보통 두 click 뒤 발생하므로 단일 클릭과 이중 클릭의 동작을 겹치게 설계하지 않는 편이 좋다.

먼저 구분할 것

div에 click만 등록하면 기본 키보드 조작이 따라오지 않는다. 버튼 기능에는 button을 쓰고 키보드로도 확인한다.

버튼, 입력 등은 오른쪽 미리보기에서 직접 조작한다. 수정 후 실행하거나 Ctrl+Enter를 누른다. 수정 내용은 파일에 자동 저장되지 않는다.

비교 예제 원문: Enter와 Space로 버튼 활성화

HTML / CSS

<button id="button" type="button">Tab으로 이동 후 Enter / Space</button>

JavaScript

// Enter와 Space로 버튼 활성화
let count = 0;
document.querySelector('#button').addEventListener('click', event => {
  count++;
  console.log('활성 횟수:', count, 'detail:', event.detail);
});

기대 결과: 키보드도 활성 횟수를 증가시키며 키보드 click의 detail은 보통 0이다.

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

div에 click만 등록하면 기본 키보드 조작이 따라오지 않는다. 버튼 기능에는 button을 쓰고 키보드로도 확인한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
