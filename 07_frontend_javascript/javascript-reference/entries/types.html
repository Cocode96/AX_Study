자료형 / typeof

원시 값과 객체를 구분하고 값의 타입을 확인한다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

받은 값에 적용할 연산이나 메서드를 판단할 때

원시 타입은 string, number, bigint, boolean, undefined, symbol, null이다. typeof null은 역사적인 이유로 object다. 배열 여부는 Array.isArray로 확인한다.

먼저 구분할 것

typeof만으로 배열과 null을 구별하지 않는다. typeof null === "object"라는 예외를 기억한다.

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

typeof만으로 배열과 null을 구별하지 않는다. typeof null === "object"라는 예외를 기억한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
