주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

기존 코드에서 함수 범위와 선언 끌어올림을 해석할 때

var는 let과 달리 블록을 범위로 삼지 않는다. 선언이 끌어올려져 대입 전 값은 undefined다. 새로운 예제는 let과 const를 기본으로 쓴다.

먼저 구분할 것

var도 함수 밖에서는 함수 내부 변수에 접근할 수 없다. 블록 범위가 없다는 말과 전역이라는 말은 다르다.

비교 예제 원문: 함수 범위는 유지된다

JavaScript

// 함수 범위는 유지된다
function example() {
  if (true) { var local = 7; }
  console.log('함수 안:', local);
}
example();
console.log('함수 밖:', typeof local);

기대 결과: 함수 안: 7 → 함수 밖: undefined

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

var도 함수 밖에서는 함수 내부 변수에 접근할 수 없다. 블록 범위가 없다는 말과 전역이라는 말은 다르다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
