event / target / currentTarget

이벤트 정보와 발생 대상, 현재 핸들러의 대상을 확인한다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

중첩된 버튼과 부모 핸들러의 대상을 구분할 때

target은 이벤트의 발생 대상, currentTarget은 현재 실행 중인 핸들러를 등록한 대상이다. 자식에서 발생한 이벤트가 버블링하면 둘이 다를 수 있다.

먼저 구분할 것

currentTarget은 이벤트 핸들러가 실행 중일 때만 유효하다. 나중에 사용할 필요가 있으면 그 시점의 값을 변수에 저장한다.

비교 예제 원문: currentTarget은 호출 중에 저장

HTML / CSS

<button id="button" type="button">대상 저장</button>

JavaScript

// currentTarget은 호출 중에 저장
document.querySelector('#button').addEventListener('click', event => {
  const current = event.currentTarget;
  console.log('호출 중:', current.id);
  setTimeout(() => {
    console.log('나중의 currentTarget:', event.currentTarget);
    console.log('저장한 요소:', current.id);
  }, 0);
});

기대 결과: 호출 중: button → 나중의 currentTarget: null → 저장한 요소: button

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

currentTarget은 이벤트 핸들러가 실행 중일 때만 유효하다. 나중에 사용할 필요가 있으면 그 시점의 값을 변수에 저장한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
