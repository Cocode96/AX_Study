JavaScript/DOM 선택과 변경

BROWSER API / 42

querySelector / getElementById

DOM 요소 하나를 찾는다.

주석 있는 예제기본 / 비교 2가지MDN 원문 ↗

이럴 때 사용한다

하나의 UI 요소를 찾아 값을 읽거나 바꿀 때

querySelector는 CSS 선택자에 맞는 첫 요소를 반환한다. 없으면 null이다. getElementById에는 # 없이 ID 문자열을 전달한다.

먼저 구분할 것

선택자에 맞는 요소가 없으면 null이다. 잘못된 CSS 선택자 문법은 예외를 던진다.

01 / SYNTAX

문법과 값의 흐름

document.querySelector("#message"); document.getElementById("message");
입력 / 조건
querySelector는 CSS 선택자, getElementById는 # 없는 ID
결과 / 반환값
첫 일치 요소. 찾지 못하면 null
원본 / 상태 변경
조회만으로 DOM을 변경하지 않는다.

// 없을 때 처리 흐름
const missing = document.querySelector('#missing');
if (missing === null) console.warn('요소를 찾지 못했습니다.');
const message = document.getElementById('message');
message.textContent = '정상적으로 찾은 요소';

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

선택자에 맞는 요소가 없으면 null이다. 잘못된 CSS 선택자 문법은 예외를 던진다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
