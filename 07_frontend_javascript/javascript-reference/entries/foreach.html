문법과 값의 흐름

list.forEach((value, index) => { ... });

콜백 (value,index,array)
결과 / 반환값
반환값은 항상 undefined
원본 / 상태 변경
메서드 자체는 변경하지 않지만 콜백에서 변경할 수 있다.

03 / TROUBLESHOOTING

이 항목에서 자주 헷갈리는 점

결과 배열을 받고 싶다면 map을 쓴다. 반복을 중단해야 하면 for...of 등으로 표현한다.

오류 메시지로 확인할 위치
ReferenceError
이름 오타, 선언 위치와 선언 전 접근을 확인한다.
TypeError
null이나 undefined인지, 해당 타입에서 호출 가능한 메서드인지 확인한다.
SyntaxError
괄호, 따옴표, 쉼표와 문법을 확인한다. 구문 오류는 예제 실행 전에 표시된다.
