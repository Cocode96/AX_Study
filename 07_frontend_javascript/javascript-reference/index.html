이번 참고서의 범위

변수와 함수, Promise와 async/await 같은 JavaScript 언어 문법을 DOM, 이벤트, fetch 같은 브라우저 API와 구분해 다룬다. AJAX의 부분 갱신 예제는 오프라인에서도 동작한다. 모듈과 저장소 API는 이번 범위에 포함하지 않는다.
