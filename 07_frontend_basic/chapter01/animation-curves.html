CSS에도 Animation Curve가 있다!

모든 공이 같은 거리를 같은 시간에 이동합니다. animation-timing-function만 달라서 중간 속도가 달라집니다. 색상의 H 값도 같은 곡선으로 0 → 360까지 변합니다.

linear처음부터 끝까지 일정한 속도
ease느리게 시작 → 빨라짐 → 느리게 도착
ease-in천천히 출발해서 가속
ease-out빠르게 출발해서 감속
ease-in-out출발과 도착을 모두 부드럽게
cubic-bezier(0.9, 0, 0.1, 1)직접 지정한 곡선: 중간에 급격히 이동
steps(6, end)6단계로 뚝뚝 끊어서 이동

직접 바꿔볼 핵심 CSS

/* @keyframes = 무엇이 변하는가 */
@keyframes travel {
  from { left: 0; --hue: 0; }
  to   { left: calc(100% - 42px); --hue: 360; }
}

/* timing-function = 시간에 따라 얼마나 진행하는가 */
animation-timing-function: cubic-bezier(0.9, 0, 0.1, 1);
animation-duration: 3s;
animation-direction: alternate; /* 도착하면 역방향으로 재생 */

설명은 왼쪽 → 오른쪽 진행 기준입니다. 돌아올 때는 곡선도 반대로 재생됩니다. 이동과 색 변화는 CSS가 처리하고, 아래 JavaScript는 버튼과 시간 선택만 처리합니다.
