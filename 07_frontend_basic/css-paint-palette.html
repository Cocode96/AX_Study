그림물감 팔레트

준비된 색 조합과 혼합 비율을 선택하고, 배경색의 알파와 요소의 opacity를 비교한다.

실제 안료 혼합을 재현하지 않는다. CSS color-mix()가 sRGB 색 공간에서 두 색을 보간한다. 노랑과 파랑을 섞어도 실제 물감처럼 초록이 되지 않을 수 있다.

이 브라우저는 color-mix()를 지원하지 않아 중간색을 표시할 수 없다.

/* 라디오 선택에 따라 변수 값을 바꾼다. */
.result-area { --a: #ff0000; --b: #0000ff; --ratio: 50%; }
#ratio-25:checked ~ .result-area { --ratio: 25%; }
.swatch-result {
  background: color-mix(in srgb, var(--a), var(--b) var(--ratio));
}
/* 기본 빨강과 파랑의 50% 혼합은 #800080에 해당한다. */

HEX의 #RRGGBB는 빨강, 초록, 파랑을 각각 16진수 두 자리로 표현한다. 00은 0, FF는 255다. #ff0000은 빨강, #0000ff는 파랑이다.

2. 배경만 투명하게 / 요소 전체를 투명하게

rgba(): 배경색에만 적용
글자와 테두리는 유지
opacity: 요소 전체에 적용
글자와 테두리도 투명
.alpha-area { --alpha: 0.5; }
#alpha-0:checked ~ .alpha-area { --alpha: 0; }
.background-only { background: rgba(128, 0, 128, var(--alpha)); }
.whole-element {
  background: rgb(128, 0, 128);
  opacity: var(--alpha);
}

알파는 0이면 완전 투명, 1이면 완전 불투명이다. opacity:0이 되어도 배치 공간은 남는다. 실제 보이는 색은 뒤에 있는 배경과도 합성된다.
