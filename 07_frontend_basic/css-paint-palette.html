그림물감 팔레트

두 색의 비율을 바꾸고, 같은 색에 투명도를 적용해 보는 웹 색상 실험이다.

실제 안료 혼합을 재현하지 않는다. 여기서는 sRGB의 R/G/B 숫자를 비율에 따라 선형 보간한다. 노랑과 파랑을 섞어도 실제 물감처럼 초록이 되지 않을 수 있다.

1. 두 색을 골라 중간색 만들기

색 A
중간색
색 B

HEX의 #RRGGBB는 빨강, 초록, 파랑을 각각 16진수 두 자리로 표현한다. 00은 0, FF는 255다. #ff0000은 빨강, #0000ff는 파랑이다.

2. 배경만 투명하게 / 요소 전체를 투명하게

rgba(): 배경색에만 적용
글자와 테두리는 유지
opacity: 요소 전체에 적용
글자와 테두리도 투명

알파는 0이면 완전 투명, 1이면 완전 불투명이다. opacity:0이 되어도 배치 공간은 남는다. 실제 보이는 색은 뒤에 있는 배경과도 합성된다.
