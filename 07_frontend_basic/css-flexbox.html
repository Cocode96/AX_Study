상자는 줄어들지 않도록 설정했다. 공간이 부족하면 넘치고, 줄바꿈을 허용하면 다음 줄로 이동한다. reverse는 주축의 시작과 끝을 뒤집는다. 예제는 왼쪽에서 오른쪽으로 읽는 가로쓰기 기준이다.

/* 부모의 기본 배치 */
.playground { display: flex; gap: 12px; align-items: center; }
/* 선택된 라디오 뒤에 있는 창 안의 부모를 변경 */
#dir-column:checked ~ .preview-scroll .playground {
  flex-direction: column;
}
#wrap:checked ~ .preview-scroll .playground { flex-wrap: wrap; }
/* 추가 아이템은 CSS로 표시 여부만 변경 */
.extra { display: none; }
#more:checked ~ .preview-scroll .extra { display: block; }

2. 부모에 쓰는 것과 자식에 쓰는 것

대상속성존재 이유
부모display: flex직계 자식에게 Flexbox 배치를 적용한다.
부모flex-direction주축의 방향을 정한다.
부모justify-content주축 방향으로 남는 공간을 배분한다.
부모align-items각 줄 안에서 자식을 교차축 방향으로 정렬한다.
부모flex-wrap공간이 부족할 때 줄바꿈을 허용할지 정한다.
부모gap자식 또는 줄 사이에 간격을 둔다. 바깥 여백은 만들지 않는다.
부모align-content여러 줄을 허용하는 컨테이너에서 줄 묶음의 교차축 배치를 정한다.
자식flexgrow / shrink / basis로 늘어남, 줄어듦, 기준 크기를 정한다.
자식align-self그 자식만 align-items와 다르게 정렬한다.

justify-content가 언제나 가로 정렬인 것은 아니다. row에서는 가로가 주축이고 column에서는 세로가 주축이다.

stretch는 교차축 크기가 auto일 때 늘린다. wrap 상태의 줄 묶음과 각 줄 안의 아이템 정렬도 구분해야 한다.

3. flex: 늘어남 / 줄어듦 / 기준 크기

grow: 1
grow: 2
grow: 1
.parent { display: flex; gap: 12px; }
.child {
  flex: 1 1 0;
  /* 1: 남는 공간을 받는다.
     1: 부족하면 줄어들 수 있다.
     0: 주축의 기준 크기를 0에서 시작한다. */
  min-width: 0; /* 긴 내용이 기본 최소 너비로 버티지 않도록 허용 */
}
.child:nth-child(2) { flex-grow: 2; }

grow:2가 어떤 상황에서나 최종 박스 너비 두 배를 뜻하지는 않는다. 기준 크기, 여백, 최소 크기도 계산에 참여한다. shrink는 shrink 값과 기준 크기를 함께 고려해 부족한 공간을 나눈다.

4. 메뉴는 왼쪽, 로그인은 오른쪽

AX홈학습 기록로그인
.menu { display: flex; align-items: center; gap: 12px; }
.login { margin-left: auto; }
/* 로그인 왼쪽의 auto margin이 같은 줄의 남는 공간을 차지한다. */

내용과 테두리 사이에는 padding, 아이템 사이에는 gap, 특정 요소 바깥 간격에는 margin을 사용한다.
