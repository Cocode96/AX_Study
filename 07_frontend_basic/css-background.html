background / 요소 뒤에 배경 그리기

색, 이미지, 크기, 반복, 위치를 따로 정하고 마지막에 단축 표기로 묶어 본다.

1. 배경 이미지 설정 바꿔 보기

반복은 120px 70px을 선택하면 잘 보인다. contain은 빈 공간, cover는 모서리 글자가 잘리는지 비교한다. 노란 부분은 이미지 밖의 background-color다.

background-position은 배경 이미지 위치다. HTML 요소 자체를 움직이는 position과 다르다. center는 배경의 가운데를 맞추며, 20px 30px은 가로/세로 간격이다. % 위치는 남는 공간에 대한 비율이므로 이미지가 축을 꽉 채우면 그 축의 위치 변화가 보이지 않을 수 있다.

2. contain / cover / 강제 크기

contain: 이미지 전체 보이기

cover: 영역 빈틈없이 채우기

contain과 cover는 이미지 비율을 유지한다. 100% 100%처럼 가로와 세로를 모두 강제로 지정하면 그림이 늘어날 수 있다.

.hero {
  height: 280px; /* 배경 자체는 높이를 만들지 않으므로 영역을 확보한다. */
  background: #fff1d6 url("images/photo.jpg") center / cover no-repeat;
  /* 색 / 이미지 / 위치 / 크기 / 반복 여부 */
}

단축 표기의 /는 위치와 크기를 구분한다. background:blue처럼 다시 지정하면 생략한 이미지, 크기 등의 설정이 초기화된다. 색만 바꾸려면 background-color를 사용한다.

3. 배경 레이어와 그라디언트

그림 위에 반투명 그라디언트를 올리면
글자가 더 잘 보인다.
background-image:
  linear-gradient(90deg, rgba(0,0,0,.75), rgba(0,0,0,.1)),
  url("images/photo.jpg");
/* 먼저 적은 그라디언트가 위, 사진이 아래다. 색은 이미지들 뒤에 놓인다. */

의미 있는 사진이나 상품 이미지는 alt를 제공할 수 있는 img가 적합하다. CSS 배경은 장식에 주로 사용한다.

4. 어디까지 칠할까? background-clip

내용 영역 / 바깥에 padding 24px / 점선 테두리 12px

background-clip은 그리기를 허용할 범위다. border-box는 테두리 아래까지, padding-box는 테두리 안쪽까지, content-box는 내용 영역만 칠한다.

background-origin은 배경 이미지 위치와 크기를 계산할 기준 영역이다. 기본값은 padding-box다. clip의 기본값 border-box와 역할이 다르며 origin은 배경색에는 영향을 주지 않는다.

5. 스크롤과 배경의 관계

각 상자 안을 스크롤하면서 빨간 선을 비교한다. 상자를 Tab으로 선택한 후 방향키로도 스크롤할 수 있다.

scroll: 요소의 배경으로 고정

내부 콘텐츠가 움직여도
빨간 배경 선은 제자리다.

아래로 스크롤

local: 내부 콘텐츠와 함께 이동

내부 콘텐츠와 함께
빨간 배경 선도 움직인다.

아래로 스크롤

background-attachment: scroll; /* 기본값, 요소 기준 */
background-attachment: local;  /* 내부 스크롤 콘텐츠 기준 */
background-attachment: fixed;  /* 뷰포트 기준으로 배경 고정 */

fixed는 요소 자체를 화면에 고정하는 position:fixed와 다르다. 배경 이미지의 기준이 바뀌며 요소는 원래 배치에 따라 움직인다.
