CSS :: 가상 요소

HTML에 장식용 태그를 추가하지 않고 앞뒤에 글자나 도형을 만든다.

: 가상 클래스 예제 보기 →

1. 링크 뒤에 아이콘

네이버 (새 탭)

::after { content: " ↗"; }

2. 필수 입력 표시

별표는 장식이다. 입력 필수 여부는 HTML의 required로 지정한다.

3. 제목 아래 구분선

빈 ::after에 너비, 높이, 배경색을 주면 선이 된다.

4. 말풍선 꼬리

안녕 나는 까마귀. 아래 꼬리는 ::after야!

본문은 HTML에 있고, 꼬리만 CSS가 그린다.

5. 마우스를 올리면 나타나는 밑줄

Tab 키로 버튼에 포커스를 옮겨도 밑줄이 나타난다. 클릭 기능 없이 효과를 보여 주는 버튼이다.

6. 선택한 메뉴에 점과 체크

라디오나 메뉴 이름을 클릭해 봐. 실제 페이지 이동 없이 선택 표시만 바뀐다.

7. content: ""로 만든 상자

왼쪽 파란 상자는 별도 HTML 태그가 없다.

content: ""는 빈 가상 요소를 만든다. content: none은 만들지 않는다.
