CSS : 가상 클래스

새 장식을 만드는 ::와 달리, 기존 요소의 상태나 조건에 따라 스타일을 적용한다.

:: 가상 요소 예제 보기 →

1. :hover / :active

올리면 연한 파랑, 누르고 있는 동안 진한 파랑. 클릭 후 선택 상태를 유지하는 기능은 아니다.

2. :focus / :focus-visible

다른 곳으로 포커스를 옮기면 다시 흐려진다. Tab 키로 이동하며 포커스 테두리도 확인해 봐.

3. :focus-within

자식 input에 포커스가 생기면 부모 카드의 배경과 테두리도 바뀐다.

4. :checked와 바로 다음 형제 선택자 +

체크하면 문구가 초록색으로 바뀐다. 체크 표시 예제이며 실제 음악은 재생하지 않는다.

5. :enabled / :disabled

왼쪽은 hover 효과가 있고, 오른쪽은 클릭과 Tab 포커스를 받지 않는다. 별도 실행 기능은 없다.

6. :valid / :invalid / :not()

abc는 빨강, crow@example.com은 초록. 지우면 기본 색이다. 브라우저의 형식 검사이며 실제 주소 존재 여부를 확인하지는 않는다.

7. :first-child / :last-child / :nth-child() / :not()

  • 첫 번째: 파란색 굵은 글씨, 홀수 배경
  • 두 번째: 짝수 배경, 위쪽 점선
  • 세 번째: 홀수 배경, 위쪽 점선
  • 네 번째: 짝수 배경, 위쪽 점선
  • 마지막: 홀수 배경, 아래쪽 파란 선

:not(:first-child)는 첫 번째 자식을 제외한 요소를 선택한다.
