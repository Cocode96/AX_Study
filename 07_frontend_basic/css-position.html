position / 배치 기준 정하기

position은 배치 방식, top/right/bottom/left는 그 기준에서의 간격이다. background-position은 배경 이미지 위치를 정하는 별도 속성이다.

1. static / relative / absolute 비교

1 / 앞의 박스
2 / 움직일 박스
3 / 다음 박스

relative는 이동 전 자리가 남으므로 3번 박스가 올라오지 않는다. absolute는 배치에서 빠지므로 3번 박스가 빈 자리로 올라온다. 둘 다 이동한 곳에서 다른 내용과 겹칠 수 있다.

top:24px는 기준의 위쪽에서 24px, left:24px는 왼쪽에서 24px이다. 0 이외의 길이에는 px, rem 같은 단위가 필요하다.

2. 부모 relative + 자식 absolute

NEW카드 오른쪽 위에 배지를 붙인 예제다.
.card { position: relative; }
.badge {
  position: absolute;
  top: 12px;
  right: 12px;
}

일반적인 구조에서는 가장 가까운 position이 static이 아닌 조상을 기준으로 배치한다. 위 카드가 그 기준이다.

기준이 되는 조상이 없으면 초기 컨테이닝 블록을 사용한다. transform이나 filter 같은 속성도 배치 기준을 만들 수 있으므로, 항상 바로 위 부모를 기준으로 한다고 외우면 안 된다.

3. fixed: 페이지를 내려도 같은 화면 위치

체크한 뒤 페이지를 스크롤하면 고정 박스가 화면 오른쪽 아래에 남는다. 박스 안의 닫기 버튼으로 숨길 수 있다.

.fixed-chip {
  position: fixed;
  right: 16px;
  bottom: 16px;
  z-index: 10;
}

fixed는 원래 배치 공간을 차지하지 않아 콘텐츠를 가릴 수 있다. 이 페이지는 아래쪽 여백을 두었다. 조상에 transform 등이 있으면 뷰포트 대신 그 조상을 기준으로 삼을 수 있다.

4. sticky: 스크롤 중 기준선에 달라붙기

아래 상자 안을 스크롤한다. 파란 제목이 위에 닿으면 붙고, 제목이 속한 영역이 끝나면 함께 밀려 올라간다.

처음에는 제목이 이 아래에 있다.
이 상자 안에서 아래로 스크롤

position: sticky; top: 0;

제목이 속한 영역

원래 배치 공간은 유지한다.

파란 제목을 확인하면서 더 내려 본다.

다음 영역
앞 영역이 끝나면 파란 제목도 올라간다.
.scroll-container { height: 260px; overflow: auto; }
.title { position: sticky; top: 0; }

sticky에는 top 같은 기준값과 움직일 여유 공간이 필요하다. 조상의 overflow 설정 때문에 예상과 다른 스크롤 영역을 기준으로 삼는 경우도 있다. fixed처럼 화면 전체에 영구 고정되는 방식은 아니다.

5. 겹쳤을 때 위에 보일 요소: z-index

파랑
z-index: 1
주황
z-index: 2
.blue { position: absolute; z-index: 1; }
.orange { position: absolute; z-index: 2; }
/* 이 예제에서 파랑을 3으로 바꾸면 주황 위에 보인다. */

같은 쌓임 맥락 안에서 비교하는 예제다. 서로 다른 부모의 쌓임 맥락에 속하면 자식의 숫자만 크게 해도 다른 부모 위로 올라가지 못할 수 있다.

한눈에 비교

값배치 기준원래 자리
static일반 배치 흐름, top/left 등은 적용되지 않음차지함
relative자신의 원래 위치에서 이동유지함
absolute배치 기준을 만드는 조상 등의 컨테이닝 블록빠짐
fixed기본적으로 뷰포트빠짐
sticky스크롤 영역과 자신의 컨테이닝 블록 범위유지함

메뉴와 카드의 일반적인 줄 배치는 Flexbox/Grid, 배지나 겹침과 고정 위치에는 position을 조합한다.
