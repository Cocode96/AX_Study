3. 박스, 여백과 hr

메뉴

메뉴 내용

제목의 밑줄

이쪽은 border-bottom으로 구분했다.

내용 → padding → border → margin 순서다. 위 박스는 padding 20px, border 1px, 위아래 margin 16px을 사용한다.

.box { display: inline-block; padding: 20px; }
.box hr {
    border: 0;
    border-top: 1px solid #a7b4c7;
    margin: 16px 0;
}

hr은 내용의 주제 구분을 나타낸다. 부모 박스가 실제로 두 개가 되지는 않는다. 제목 아래 장식선이면 border-bottom도 가능하다.

width: min(100%, 420px)
min-height: 90px

min-height는 높이의 하한선이다. min()은 전달한 값 중 작은 값을 선택한다. 위 예제는 부모 너비를 넘지 않으면서 최대 420px까지 넓어진다. 이 페이지는 border-box를 사용하므로 지정 너비에 padding과 border가 포함된다.

/* input, label, .menu-window는 같은 부모의 자식이다. */
.nav-bar { transform: translateX(-100%); transition: transform 0.4s ease; }
.nav-bar-btn:checked ~ .menu-window .nav-bar {
    transform: translateX(0);
}

:checked는 선택된 입력, ~는 뒤에 있는 형제를 뜻한다. 그 뒤의 공백은 창 안의 자손을 선택한다. 실제 코드에는 닫힌 메뉴를 숨기는 visibility도 포함했다.

translateX(100px)는 오른쪽 100px, rotate(10deg)는 10도 회전이다. translate(100), rotate:10처럼 0이 아닌 값에 단위를 빼면 적용되지 않는다. translateX(-100%)의 %는 움직이는 요소 자신의 너비 기준이다.

6. @keyframes로 등장 동작 정의하기

아래에서 올라오면서 나타나는 박스
@keyframes arrive {
    from { opacity: 0; transform: translateY(20px); }
    to   { opacity: 1; transform: translateY(0); }
}
#arrive-btn:checked ~ .arrival-stage .arrival-card {
    animation: arrive 0.4s ease forwards;
    /* 이름 / 시간 / 속도 변화 / 종료 상태 유지 */
}

정확한 이름은 복수형 @keyframes다. 정의만 해 두면 실행되지 않는다. 체크를 해제하면 animation 연결이 풀리며 즉시 숨겨지고, 다시 체크하면 처음부터 실행된다. forwards는 재생 후 마지막 키프레임 상태를 유지한다.

transition은 값이 바뀔 때 두 상태를 연결하고, animation은 정의한 키프레임을 재생한다. 같은 요소의 transform에 둘을 겹치지 않도록 위 메뉴와 등장 박스를 나누었다.

7. 올리기, 누르기, 선택 유지에 그림자 주기

.shadow-demo:hover {
    box-shadow: 0 6px 12px rgba(0, 0, 0, 0.2);
    /* 좌우 / 위아래 / 흐림 / 색과 불투명도 */
}
.shadow-demo:active { transform: translateY(2px); }
.shadow-choice:checked + .shadow-demo {
    box-shadow: 0 6px 12px rgba(0, 0, 0, 0.25);
}

hover는 마우스가 위에 있는 동안, active는 누르는 동안이다. 선택 유지에는 checkbox의 checked를 쓴다. 여기서는 label이 input 바로 다음이라 +로 선택한다. 두 번째 값이 양수면 아래쪽, 음수면 위쪽 그림자다.

선택 유지 예제는 체크 후 마우스를 다른 곳으로 옮겨 확인한다. box-shadow는 주변 요소를 밀어내지 않는다. inset을 붙이면 박스 안쪽으로 그림자가 생긴다.
