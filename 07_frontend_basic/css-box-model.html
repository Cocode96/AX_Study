CSS NOTES / 01

150 × 50인데,
왜 박스는 더 커질까?

기본값인 box-sizing: content-box에서 width와 height는 내용 영역의 크기다. 여기에 안쪽 여백과 테두리가 더해져 화면에 보이는 박스 크기가 정해진다.

입력한 CSS

.box {
    width: 150px;          /* 내용의 너비 */
    height: 50px;          /* 내용의 높이 */
    margin: 50px;          /* 바깥 여백 */
    padding: 30px;         /* 안쪽 여백 */
    border: 5px solid blue;/* 테두리 */
}

별도 box-sizing 설정이 없는 일반적인 블록 요소를 기준으로 설명한다. margin과 padding에 값 하나를 쓰면 위, 오른쪽, 아래, 왼쪽 모두에 적용된다.

브라우저에서 그려지는 구조

margin 50px padding 30px
150 × 50
내용paddingbordermargin

실제 CSS 크기로 표시한 예제 / 단위: CSS px

내용, padding, margin의 배경색은 설명을 위해 추가했다. 원본 CSS는 파란 테두리만 지정하며, margin 자체에는 배경색이 칠해지지 않는다.

각 속성은 어디에 적용될까?

속성역할이 코드에서의 의미
width내용 영역의 가로 크기150px. padding, border, margin은 포함하지 않는다.
height내용 영역의 세로 크기50px. padding, border, margin은 포함하지 않는다.
padding내용과 테두리 사이의 안쪽 여백사방 30px. 요소의 배경은 기본적으로 padding 영역에도 이어진다.
borderpadding 바깥을 감싸는 테두리사방 두께 5px, 실선(solid), 파란색(blue).
margin테두리 바깥의 여백사방 50px. 주변 요소와의 간격에 관여한다.
내용 → padding → border → margin

실제 크기 계산

테두리까지의 박스 크기
220 × 120px
가로: 150 + 30 × 2 + 5 × 2 = 220px
세로: 50 + 30 × 2 + 5 × 2 = 120px
사방 margin을 단순히 더한 범위
320 × 220px
가로: 220 + 50 × 2 = 320px
세로: 120 + 50 × 2 = 220px

margin은 요소 자체의 크기에 포함되지 않는다. 또한 일반 블록 배치에서는 위아래 margin이 겹치는 ‘마진 상쇄’가 생길 수 있다. 따라서 실제 주변 간격이나 부모 높이가 언제나 위 단순 합과 같지는 않다.

여백 단축 표기 읽기

margin과 padding은 같은 순서로 읽는다.

margin: 50px;
/* 위, 오른쪽, 아래, 왼쪽: 모두 50px */

margin: 10px 20px;
/* 위아래 10px / 좌우 20px */

margin: 10px 20px 30px;
/* 위 10px / 좌우 20px / 아래 30px */

margin: 10px 20px 30px 40px;
/* 위 → 오른쪽 → 아래 → 왼쪽 */

값이 4개라면 위에서 시작해 시계 방향으로 읽으면 된다.

border-box라면?

box-sizing: border-box를 사용하면 지정한 너비와 높이에 padding과 border가 포함된다. margin은 여전히 바깥이다.

.box {
    box-sizing: border-box;
    width: 220px;
    height: 120px;
    margin: 50px;
    padding: 30px;
    border: 5px solid blue;
}

위처럼 쓰면 원본과 동일하게 테두리까지 220 × 120px, 내용은 150 × 50px가 된다.

원본의 150 × 50px를 그대로 두고 border-box만 적용하면? 내용 너비는 80px가 된다. 세로는 padding과 border만으로 70px이므로, 내용 높이는 0px까지 줄고 실제 테두리까지의 높이는 최소 70px이 된다.

CSS NOTES / 02

이미지에 움직임 주기

페이드는 opacity로 투명도를 바꾸고, 슬라이드는 transform으로 위치를 바꾼다. transition이 두 상태 사이를 부드럽게 연결한다.

01 / 페이드인

체크하면 이미지가 서서히 나타난다.
opacity: 0 → 1

체크를 해제하면 다시 서서히 사라진다.

HTML + CSS 보기
<input type="checkbox" id="show">
<label for="show">나타내기</label>
<img src="photo.jpg" alt="풍경">

/* 처음에는 투명 */
img {
  opacity: 0;
  transition: opacity 0.8s ease;
}
/* 체크된 input 뒤의 형제 img */
#show:checked ~ img {
  opacity: 1;
}

02 / 페이드아웃

체크하면 이미지가 서서히 사라진다.
opacity: 1 → 0

체크를 해제하면 다시 서서히 나타난다.

HTML + CSS 보기
<input type="checkbox" id="hide">
<label for="hide">숨기기</label>
<img src="photo.jpg" alt="풍경">

/* 처음에는 보임 */
img {
  opacity: 1;
  transition: opacity 0.8s ease;
}
/* 체크하면 투명 */
#hide:checked ~ img {
  opacity: 0;
}

03 / 이미지 슬라이드

아침, 저녁, 밤을 선택해 이동한다.
translateX(0% → -100%)

같은 name의 라디오 버튼은 한 번에 하나만 선택된다.

HTML + CSS 보기
<input type="radio" name="slide"
       id="s1" checked>
<label for="s1">1번</label>
<input type="radio" name="slide"
       id="s2">
<label for="s2">2번</label>
<div class="window">
  <div class="track">
    <img src="a.jpg" alt="아침">
    <img src="b.jpg" alt="저녁">
  </div>
</div>

.window { overflow: hidden; }
.track { display: flex;
  transition: transform 0.6s ease; }
.track img { flex: 0 0 100%;
  width: 100%; min-width: 0; }
#s1:checked ~ .window .track {
  transform: translateX(0%);
}
#s2:checked ~ .window .track {
  transform: translateX(-100%);
}

HTML과 CSS만으로 동작하는 원리

  1. HTML에서 체크박스 또는 라디오 버튼과 이미지를 만든다. label의 for를 입력 요소의 id와 맞추면 글자를 눌러도 선택된다.
  2. :checked는 선택된 입력 요소를 찾는다. ~는 같은 부모 안에서 그 요소 뒤에 있는 형제 요소를 선택한다.
  3. CSS에서 선택 전후의 opacity 또는 transform 값을 다르게 지정한다.
  4. transition이 중간 상태를 이어 준다. 0.8s는 0.8초이며, ease는 시작과 끝이 완만한 속도 변화다.

펼친 코드에서는 핵심 구조만 보여준다. 페이드 예제의 이미지를 div로 감싸면 #show:checked ~ .image-window img처럼 선택자를 맞춰야 한다. 실제 사진은 src="images/photo.jpg"처럼 연결하면 된다.

핵심 속성기억할 점
opacity0은 완전 투명, 1은 완전 불투명. 투명해져도 원래 공간과 접근성 정보는 남고, 클릭 가능 여부도 자동으로 바뀌지 않는다.
transition값이 바뀔 때 동작한다. 체크를 켜고 끄면 양방향으로 전환되며, 이미 선택된 라디오 버튼을 또 누르면 값이 그대로라 다시 움직이지 않는다.
transform이미지를 담은 트랙의 표시 위치를 이동한다. 여기서 -100%는 트랙 자신의 너비만큼 왼쪽으로 이동한다는 뜻이다.
overflow: hidden슬라이드 창 밖으로 나간 이미지를 잘라서 보이지 않게 한다.
display: none요소를 배치에서 제거한다. 이 예제의 opacity 전환과 동시에 적용하면 사라지는 과정을 볼 수 없다.

스크립트와 외부 라이브러리 없이 실행된다. 그림도 HTML에 내장되어 있다. 운영체제에서 동작 줄이기를 켰다면 효과가 즉시 전환된다.
