CSS 애니메이션

무엇을 바꿀지, 몇 초 동안 바꿀지, 어떻게 반복할지를 나누어 읽는다.

1. transition: 상태가 바뀌면 움직인다

버튼 위에 마우스를 올리거나 Tab으로 선택하면 위로 살짝 이동한다.

/* 평소 상태에 전환 규칙을 둔다. */
.button {
  transition: transform 400ms ease;
}
/* 값이 바뀌는 계기: hover */
.button:hover {
  transform: translateY(-6px);
}

400ms는 0.4초다. transition만 적어 두면 움직이지 않는다. 실제 속성값이 바뀌어야 한다.

재생을 체크하면 시작한다. 일시정지를 해제하면 이어서 움직인다. 초기화를 누른 뒤 재생을 다시 체크하면 처음부터 시작한다.

중간 시간
브라우저가 진행률 계산

도착 위치
/* input과 .track은 같은 부모 안에 있으며 input이 먼저 나온다. */
.runner { animation: none 3s ease-in-out infinite alternate; }
#play:checked ~ .track .runner { animation-name: travel; }
#pause:checked ~ .track .runner { animation-play-state: paused; }
#time-1:checked ~ .track .runner { animation-duration: 1s; }
@keyframes travel {
  from { transform: translateX(0%); }
  to   { transform: translateX(100%); }
}

HTML이 선택 상태를 보관하고 CSS가 해당 상태에 맞는 애니메이션을 적용한다. alternate는 도착 후 역방향으로 재생하므로 왕복은 편도 시간의 두 배다.

속성역할예
animation-name실행할 @keyframes 이름travel
animation-duration한 번 재생하는 시간3s
animation-timing-function시간에 따른 진행률linear, ease-in-out
animation-delay재생 시작 전 대기 시간1s
animation-iteration-count반복 횟수2, infinite
animation-direction재생 방향normal, alternate
animation-play-state재생 또는 일시정지running, paused
animation-fill-mode재생 전후 키프레임 스타일 적용 방식none, forwards, backwards, both

3. 한 번 나타난 뒤 마지막 상태 유지

체크하면 카드가 나타난다. forwards 덕분에 끝난 후에도 보인다.

opacity: 0 → 1
translateY: 20px → 0
#enter:checked ~ .arrival-stage .arrival-card {
  animation: arrive 900ms ease-out forwards;
}
@keyframes arrive {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}

이동에는 transform, 페이드에는 opacity를 사용한다. opacity:0은 공간을 없애지 않으므로 체크를 해제해도 카드 자리의 높이는 남는다. 숨긴 카드의 내용은 visibility:hidden으로 접근성 트리에서도 제외한다.
