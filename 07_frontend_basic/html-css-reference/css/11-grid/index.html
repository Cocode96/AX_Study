Grid 행과 열

Grid는 행과 열의 트랙을 먼저 정의하고 직계 자식을 셀이나 영역에 배치한다.

개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • grid-template-columns — 명시적 열 트랙의 너비를 정의한다.
  • grid-template-rows — 명시적 행 트랙의 높이를 정의한다.
  • grid-auto-rows — 명시하지 않은 암시적 행의 높이를 정한다.
  • grid-auto-columns — 암시적으로 추가되는 열의 크기를 정한다.
  • grid-auto-flow — 자동 배치되는 Grid 아이템의 진행 방향을 정한다.
  • grid-template-areas — 이름 붙인 직사각형 영역으로 Grid 틀을 정의한다.
  • justify-items — Grid 셀 안에서 자식들의 인라인 축 정렬을 정한다.
  • place-items — align-items와 justify-items를 함께 지정한다.
  • place-content — align-content와 justify-content를 함께 지정한다.
  • grid-column — 아이템의 열 시작/끝 선 또는 차지할 열 수를 정한다.
  • grid-row — 아이템의 행 시작/끝 선 또는 차지할 행 수를 정한다.
  • grid-area — 영역 이름 또는 행/열 시작/끝을 지정한다.
  • justify-self — Grid 아이템 하나의 인라인 축 정렬을 정한다.
  • repeat() — Grid 트랙 정의를 반복한다.
  • minmax() — Grid 트랙 크기의 최소/최대 범위를 정한다.
  • fr — Grid 트랙에 남은 공간을 비율로 분배하는 단위다.
