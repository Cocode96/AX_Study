CSS / property

grid-column

아이템의 열 시작/끝 선 또는 차지할 열 수를 정한다.

어디에 쓰나

Grid 아이템인 자식 .target

초깃값: auto / 상속: 아니오

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { grid-column: 1 / 3; }
값 / 문법무엇이 달라지나
1 / 31번 선부터 3번 선까지
span 2두 열 차지
1 / -1명시적 Grid의 처음부터 끝까지
auto자동 배치

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

안 되거나 헷갈릴 때

선 번호와 셀 번호를 구분한다. 1/3은 3개 열이 아닌 2개 열이다.

DevTools에서 grid-column를 검색해 선언이 취소선인지, 최종 계산값이 무엇인지 확인한다. 위의 적용 대상과 부모 조건도 같이 확인한다.
