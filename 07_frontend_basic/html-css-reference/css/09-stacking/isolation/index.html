CSS / property

isolation

새로운 독립 쌓임 맥락을 만들지 지정한다.

어디에 쓰나

순서를 정할 요소

초깃값: auto / 상속: 아니오

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { isolation: isolate; }
값 / 문법무엇이 달라지나
isolate독립 쌓임 맥락 생성
auto다른 속성에 따른 기본 동작

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

바로 수정하는 예제

isolation를 직접 바꾸기

stage 안의 target과 겹침 비교 요소가 같은 부모를 가진다. 자식의 맥락 경계를 함께 본다.

안 되거나 헷갈릴 때

혼합 모드의 그룹 경계를 만들 때 유용하다. 이 속성만으로 요소가 다른 형제보다 위에 오르지는 않는다.

DevTools에서 isolation를 검색해 선언이 취소선인지, 최종 계산값이 무엇인지 확인한다. 위의 적용 대상과 부모 조건도 같이 확인한다.
