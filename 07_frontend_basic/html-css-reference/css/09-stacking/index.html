z-index와 쌓임 맥락

z-index는 같은 쌓임 맥락 안에서 비교한다. 자식의 큰 숫자로 부모의 쌓임 순서를 무조건 벗어날 수 없다.

개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • z-index — 현재 쌓임 맥락에서 그리는 순서를 정한다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준
z-index쌓임 순서positioned 요소, Flex/Grid 아이템 등의 순서에 관여한다.
stacking context쌓임 맥락자식들의 쌓임을 하나의 묶음으로 다루는 경계다.

transform, opacity < 1맥락 생성변환이나 투명도도 새 맥락을 만들 수 있다.
