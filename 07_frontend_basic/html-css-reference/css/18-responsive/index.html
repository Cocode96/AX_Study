키워드 표실행 예제헷갈리는 점

예제는 독립된 문서로 실행됩니다. 화면 공통 스타일과 섞이지 않으며, 미리보기 안에서 직접 클릭하거나 입력할 수 있습니다. JavaScript는 코드 적용과 너비 조절을 돕습니다.

개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • @media — 뷰포트/출력 장치/사용자 설정 조건으로 CSS를 적용한다.
  • @container — 선택된 조상 컨테이너 조건에 따라 후손 스타일을 바꾼다.
  • @supports — 선언/선택자 문법 지원에 따라 CSS를 조건부 적용한다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준
@media뷰포트/환경화면 너비, 인쇄, 입력 장치, 사용자 설정 등의 조건이다.
min-width, max-width미디어 조건뷰포트 너비에 따른 규칙을 적용한다.
mobile first작성 방향작은 화면 기본값에 넓은 화면 규칙을 추가한다.
container-type: inline-size쿼리 컨테이너후손이 컨테이너의 인라인 크기를 질의하게 한다.
@container컨테이너 조건뷰포트가 아닌 조건을 만족하는 조상의 크기를 기준으로 적용한다.
hover, pointer입력 환경hover 지원 여부와 포인터 정밀도 등의 조건이다.
prefers-color-scheme색 선호사용자의 밝은/어두운 색상 선호를 감지한다.
@supports기능 질의선언/선택자 구문 지원 여부에 따라 스타일을 적용한다.
@media print인쇄인쇄 시 불필요한 UI를 숨기고 레이아웃을 조정한다.
