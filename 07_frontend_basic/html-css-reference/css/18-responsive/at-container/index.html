CSS / at-rule

@container

선택된 조상 컨테이너 조건에 따라 후손 스타일을 바꾼다.

어디에 쓰나

스타일시트 안의 @규칙. 중괄호 또는 세미콜론 구조를 예제대로 작성한다.
