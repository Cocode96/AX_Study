inherit-initial-unset-revert

속성을 상속/초기/이전 출처/레이어 상태로 되돌리는 공통 값이다.

어디에 쓰나

대부분의 CSS 속성값.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

값 / 문법무엇이 달라지나
inherit부모 계산값
initial명세 초깃값
unset상속 속성은 inherit, 나머지는 initial
revert이전 출처 수준으로 되돌림
revert-layer현재 레이어 효과 되돌림

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.
