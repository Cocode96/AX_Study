개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • @layer — 스타일 우선순위를 레이어 단위로 정리한다.
  • @import — 다른 스타일시트를 가져온다.
  • important — 선언을 중요 선언으로 표시한다.
  • inherit-initial-unset-revert — 속성을 상속/초기/이전 출처/레이어 상태로 되돌리는 공통 값이다.

키워드어디에 쓰나역할 / 기준

inline style요소의 style 속성일반 작성자 스타일에서 높은 우선순위를 가지지만 모든 선언을 이기는 것은 아니다.

헷갈리는 점

  • 동일한 출처/중요도/레이어 안에서 명시도를 비교하고, 이후 조건까지 같을 때 뒤 선언이 이긴다.
  • !important 선언에서는 레이어 순서가 반전된다. transition, animation도 캐스케이드에 별도 위치를 가진다.
  • DevTools의 Styles에서 취소선과 Computed의 최종값을 함께 확인하면 원인을 찾기 쉽다.
