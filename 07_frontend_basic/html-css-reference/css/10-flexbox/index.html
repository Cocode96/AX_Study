개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • flex-direction — Flex 컨테이너의 주축 방향을 정한다.
  • justify-content — 주축 방향의 남는 공간을 배분한다.
  • align-items — 각 줄 안에서 자식의 교차축 정렬 기본값을 정한다.
  • flex-wrap — Flex 아이템이 여러 줄로 나뉠지 정한다.
  • flex-flow — flex-direction과 flex-wrap을 함께 지정한다.
  • align-content — 여러 줄을 허용한 Flex의 줄 묶음을 교차축에 배치한다.
  • gap — 행과 열 사이의 간격을 지정한다.
  • row-gap — 행 사이의 간격을 지정한다.
  • column-gap — 열 사이의 간격을 지정한다.
  • flex-grow — 남는 주축 공간을 분배받는 성장 비율을 정한다.
  • flex-shrink — 부족한 공간을 줄여 부담할 비율을 정한다.
  • flex-basis — 남는 공간을 나누기 전 주축 기준 크기를 정한다.
  • flex — 성장/축소/기준 크기를 한 번에 지정한다.
  • align-self — 자식 하나의 교차축 정렬을 덮어쓴다.
  • order — Flex/Grid 아이템의 시각적 배치 순서를 정한다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준
display: flex부모직계 자식을 flex item으로 만든다.
flex-direction부모row/column과 reverse로 주축 방향을 정한다.
justify-content부모주축의 남는 공간을 배분한다.
align-items, align-self부모/자식교차축 정렬과 특정 자식의 예외다.
flex-wrap, align-content부모여러 줄 허용과 줄 묶음의 교차축 배치다.
gap, row-gap, column-gap부모아이템/줄 사이 간격이다. 바깥 여백은 아니다.
flex-grow, flex-shrink, flex-basis자식늘어남, 줄어듦, 주축 기준 크기를 정한다.
flex자식grow/shrink/basis 축약이다.
order자식화면 순서를 바꾸지만 DOM 읽기/포커스 순서를 함께 바꾸지 않는다.
min-width: 0자식긴 내용이 기본 최소 크기로 버티지 않게 허용할 때 사용한다.
