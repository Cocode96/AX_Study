column-gap

열 사이의 간격을 지정한다.

어디에 쓰나

Flex 컨테이너인 부모 .target

초깃값: normal / 상속: 아니오

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { column-gap: 24px; }
값 / 문법무엇이 달라지나
24px열 사이 24px
0열 간격 없음
8px좁은 열 간격

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

column-gap를 직접 바꾸기

안 되거나 헷갈릴 때
