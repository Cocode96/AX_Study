가상 요소와 장식

가상 요소는 첫 글자, 선택 영역, 생성 콘텐츠처럼 요소의 일부를 대상으로 한다.

키워드 표실행 예제헷갈리는 점

예제는 독립된 문서로 실행됩니다. 화면 공통 스타일과 섞이지 않으며, 미리보기 안에서 직접 클릭하거나 입력할 수 있습니다. JavaScript는 코드 적용과 너비 조절을 돕습니다.

개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • ::before — 요소의 앞쪽에 생성 콘텐츠 상자를 만든다.
  • ::after — 요소의 뒤쪽에 생성 콘텐츠 상자를 만든다.
  • ::first-letter — 첫 글자 일부에 스타일을 적용한다.
  • ::first-line — 블록의 첫 번째 줄에 스타일을 적용한다.
  • ::selection — 사용자가 드래그로 선택한 부분을 꾸민다.
  • ::marker — 목록의 번호/불릿을 꾸민다.
  • ::placeholder — 입력의 placeholder 텍스트를 꾸민다.
  • ::file-selector-button — 파일 input의 기본 선택 버튼을 꾸민다.
  • ::backdrop — 상위 레이어 요소 뒤의 배경을 꾸민다.
  • content — 가상 요소의 생성 콘텐츠를 지정한다.
  • counter-reset — CSS 카운터의 시작 상태를 만든다.
  • counter-increment — 요소마다 CSS 카운터 값을 증가시킨다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준
::before, ::after생성 콘텐츠요소의 앞/뒤에 CSS 생성 상자를 만든다. 보통 content가 필요하다.
content생성 콘텐츠 속성문자열, 빈 문자열, 카운터 등을 지정한다.
::first-letter, ::first-line텍스트 일부첫 글자 또는 첫 줄에 제한된 속성을 적용한다.
::selection사용자 선택드래그로 선택한 텍스트 영역의 색 등을 바꾼다.
::marker목록 표시목록 번호/불릿에 허용되는 속성을 적용한다.
::placeholder입력 안내placeholder 텍스트의 모양이다.
::file-selector-button파일 입력파일 선택 버튼을 꾸민다.
::backdrop상위 레이어 배경모달 dialog 등 뒤의 배경이다.
counter-reset, counter-increment카운터CSS로 생성한 순번을 관리한다.
