CSS / property

counter-reset

CSS 카운터의 시작 상태를 만든다.

어디에 쓰나

가상 요소 또는 카운터를 관리할 요소

초깃값: none / 상속: 아니오

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { counter-reset: step 0; }
값 / 문법무엇이 달라지나
step 0step 카운터를 0으로 시작
step 33에서 시작
none카운터 초기화 없음

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

바로 수정하는 예제

counter-reset를 직접 바꾸기

content는 ::before/::after에, 카운터는 초기화 부모와 증가 자식에 각각 작성한다.

안 되거나 헷갈릴 때

번호 증가는 counter-increment, 출력은 content:counter(...)가 담당한다.

DevTools에서 counter-reset를 검색해 선언이 취소선인지, 최종 계산값이 무엇인지 확인한다. 위의 적용 대상과 부모 조건도 같이 확인한다.
