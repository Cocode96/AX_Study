필터, 합성과 클리핑

필터는 렌더링 결과를 처리하고, 클리핑은 보일 영역을 제한한다. 자식의 개별 스타일과 부모 전체 결과에 적용하는 효과를 구분한다.

예제는 독립된 문서로 실행됩니다. 화면 공통 스타일과 섞이지 않으며, 미리보기 안에서 직접 클릭하거나 입력할 수 있습니다. JavaScript는 코드 적용과 너비 조절을 돕습니다.

개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • filter — 자손을 포함한 요소 렌더링 결과에 필터를 적용한다.
  • backdrop-filter — 요소 뒤에 비치는 배경 결과를 처리한다.
  • mix-blend-mode — 요소 결과와 뒤쪽 배경을 섞는 방식을 정한다.
  • background-blend-mode — 요소 안의 배경 레이어끼리 혼합한다.
  • clip-path — 보이는 영역을 도형 경계로 자른다.
  • mask-image — 마스크 이미지로 요소가 보이는 정도를 제어한다.
  • blur() — 주변 픽셀을 섞어 흐림 효과를 만든다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준
filter: blur(), brightness(), contrast()요소 결과흐림, 밝기, 대비 등을 처리한다.
grayscale(), saturate(), hue-rotate()색 처리회색조, 채도, 색상 회전이다.
drop-shadow()필터 그림자요소의 알파 형태를 따른 그림자다. box-shadow와 다르다.
backdrop-filter뒤쪽 배경요소 뒤에 보이는 영역을 처리한다. 반투명 배경과 함께 쓰는 경우가 많다.
mix-blend-mode요소 합성뒤 배경과 색을 섞는 방식이다.
background-blend-mode배경 합성한 요소의 여러 배경 레이어를 혼합한다.
isolation: isolate합성 경계그룹 바깥 배경과의 섞임을 제한하는 데 사용한다.
clip-path자르기circle(), polygon(), inset() 등의 영역 안을 보인다.
mask-image마스크이미지의 알파/밝기 등을 이용해 표시 정도를 제어한다.

헷갈리는 점

  • :blur라는 가상 클래스는 없다. 흐림은 filter:blur(), 포커스 조건은 :focus다.
