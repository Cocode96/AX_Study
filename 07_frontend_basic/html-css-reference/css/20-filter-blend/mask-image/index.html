CSS / property

mask-image

마스크 이미지로 요소가 보이는 정도를 제어한다.

어디에 쓰나

렌더링 효과를 줄 요소 .target

초깃값: none / 상속: 아니오

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { mask-image: linear-gradient(to right, black, transparent); }
값 / 문법무엇이 달라지나
linear-gradient(to right, black, transparent)오른쪽으로 서서히 사라짐
radial-gradient(black 40%, transparent 70%)중앙만 남기기
none마스크 없음

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

바로 수정하는 예제

mask-image를 직접 바꾸기

뒤쪽 패턴 위의 결과를 비교한다. 부모에 적용한 후처리는 자식에까지 영향을 줄 수 있다.

안 되거나 헷갈릴 때

알파 마스크에서는 검정도 불투명하다. clip-path처럼 단순한 경계만 자르는 방식과 다르다.

DevTools에서 mask-image를 검색해 선언이 취소선인지, 최종 계산값이 무엇인지 확인한다. 위의 적용 대상과 부모 조건도 같이 확인한다.
