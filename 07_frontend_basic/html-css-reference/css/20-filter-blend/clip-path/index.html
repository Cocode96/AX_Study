clip-path

보이는 영역을 도형 경계로 자른다.

어디에 쓰나

렌더링 효과를 줄 요소 .target

초깃값: none / 상속: 아니오

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { clip-path: circle(45%); }
값 / 문법무엇이 달라지나
circle(45%)원형 표시
inset(10px round 16px)안쪽 사각형과 둥근 모서리
polygon(50% 0, 100% 100%, 0 100%)삼각형
none자르기 없음

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

안 되거나 헷갈릴 때

레이아웃 공간은 원래 박스로 남는다. 잘린 영역은 히트 테스트에도 영향을 준다.

DevTools에서 clip-path를 검색해 선언이 취소선인지, 최종 계산값이 무엇인지 확인한다. 위의 적용 대상과 부모 조건도 같이 확인한다.
