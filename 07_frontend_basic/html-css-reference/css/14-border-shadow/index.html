테두리, 외곽선과 그림자

테두리는 박스 크기 계산에 참여하고, outline과 box-shadow는 일반적으로 주변 레이아웃 공간을 확보하지 않는다.

키워드 표실행 예제헷갈리는 점

예제는 독립된 문서로 실행됩니다. 화면 공통 스타일과 섞이지 않으며, 미리보기 안에서 직접 클릭하거나 입력할 수 있습니다. JavaScript는 코드 적용과 너비 조절을 돕습니다.

개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • border — 테두리 두께, 선 종류, 색을 축약 지정한다.
  • border-width — 네 방향 테두리의 두께를 지정한다.
  • border-style — 테두리 선의 종류를 정한다.
  • border-color — 테두리 색을 정한다.
  • border-radius — 박스 모서리의 곡률을 정한다.
  • outline — 박스 공간을 늘리지 않는 외곽선을 그린다.
  • outline-offset — 외곽선과 테두리 사이 거리를 정한다.
  • box-shadow — 박스 외곽 또는 내부 그림자를 그린다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준
border-width, border-style, border-color테두리두께, 선 종류, 색이다.
border-radius모서리모서리를 둥글게 한다. 크기 대비 %는 타원을 만들 수 있다.
outline, outline-offset외곽선포커스 표시 등에 사용하며 박스 크기를 늘리지 않는다.
box-shadow박스 그림자x/y 오프셋, blur, spread, 색 순으로 지정한다.
inset내부 그림자box-shadow를 박스 안쪽에 그린다.
text-shadow글자 그림자텍스트에 x/y 오프셋, blur, 색을 지정한다.
border-image이미지 경계이미지를 분할해 테두리로 사용한다.
