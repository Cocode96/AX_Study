CSS / property

border-width

네 방향 테두리의 두께를 지정한다.

어디에 쓰나

크기를 지정할 요소

초깃값: medium / 상속: 아니오

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { border-width: 6px; }
값 / 문법무엇이 달라지나
6px네 방향 6px
2px 8px위아래 2px 좌우 8px
0두께 없음

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

border-width를 직접 바꾸기

안 되거나 헷갈릴 때

보이는 테두리를 위해 border-style도 필요하다.

DevTools에서 border-width를 검색해 선언이 취소선인지, 최종 계산값이 무엇인지 확인한다. 위의 적용 대상과 부모 조건도 같이 확인한다.
