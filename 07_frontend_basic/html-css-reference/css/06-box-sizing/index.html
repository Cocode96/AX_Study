개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • width — 요소의 가로 크기를 지정한다.
  • height — 요소의 세로 크기를 지정한다.
  • min-width — 요소가 줄어들 수 있는 최소 너비를 제한한다.
  • max-width — 요소가 커질 수 있는 최대 너비를 제한한다.
  • min-height — 최소 높이를 확보하면서 필요하면 더 커지도록 한다.
  • max-height — 요소의 최대 높이를 제한한다.
  • padding — 내용과 테두리 사이의 안쪽 여백을 정한다.
  • padding-top — 내용 위쪽의 안쪽 여백을 지정한다.
  • padding-right — 내용 오른쪽의 안쪽 여백을 지정한다.
  • padding-bottom — 내용 아래쪽의 안쪽 여백을 지정한다.
  • padding-left — 내용 왼쪽의 안쪽 여백을 지정한다.
  • margin — 테두리 바깥의 여백을 지정한다.
  • margin-top — 요소 위쪽의 바깥 여백을 지정한다.
  • margin-right — 요소 오른쪽의 바깥 여백을 지정한다.
  • margin-bottom — 요소 아래쪽의 바깥 여백을 지정한다.
  • margin-left — 요소 왼쪽의 바깥 여백을 지정한다.
  • box-sizing — width와 height가 포함하는 박스 범위를 정한다.
  • aspect-ratio — 자동 크기 계산에 사용할 선호 가로:세로 비율을 정한다.
