개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • :hover — 포인터가 위에 있는 동안의 상태다.
  • :active — 사용자가 요소를 활성화하는 동안의 상태다.
  • :focus — 입력 포커스를 가진 요소를 고른다.
  • :focus-visible — 브라우저가 포커스 표시가 필요하다고 판단한 요소다.
  • :disabled — HTML상 비활성 상태인 지원 컨트롤을 고른다.
  • :enabled — 활성 상태인 지원 컨트롤을 고른다.
  • :valid — HTML 입력 조건을 충족하는 입력을 고른다.
  • :invalid — HTML 입력 조건을 충족하지 못하는 입력을 고른다.
  • :required — required 조건이 있는 입력을 고른다.
  • :placeholder-shown — placeholder가 현재 표시 중인 입력을 고른다.
  • :checked — checkbox/radio의 현재 선택 상태를 고른다.
  • :focus-within — 자신 또는 후손 중 포커스가 있는 요소를 고른다.
  • :first-child — 형제 요소 중 첫 번째인 대상을 고른다.
  • :last-child — 형제 요소 중 마지막인 대상을 고른다.
  • :nth-child() — 같은 부모의 요소 자식 순서로 선택한다.
  • :nth-of-type() — 같은 타입의 형제끼리 센 순서로 선택한다.
  • :only-child — 유일한 요소 자식인 대상을 선택한다.
  • :not() — 인수 조건에 맞지 않는 요소를 고른다.
  • :is() — 여러 선택자 중 하나에 맞는 대상을 묶는다.
  • :where() — 명시도 0으로 선택자 조건을 묶는다.
  • :has() — 상대 선택자 조건을 만족하는 요소가 있는지 검사한다.
  • :target — URL의 #조각과 id가 일치하는 요소를 고른다.
  • :root — 문서 루트 요소를 선택한다.
  • :empty — 자식 요소와 의미 있는 텍스트 내용이 없는 요소를 선택한다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준
:hover, :active사용자 동작위에 올린 동안, 활성화하는 동안을 선택한다.
:focus, :focus-visible, :focus-within포커스현재 포커스, 필요한 포커스 표시, 자신 또는 후손의 포커스다.
:checked, :disabled, :enabled폼 상태선택 여부와 활성 상태를 검사한다.
:valid, :invalid, :required입력 조건HTML 검증 상태 또는 필수 입력 여부를 검사한다.
:placeholder-shown, :empty내용 조건플레이스홀더 표시와 빈 요소 조건이다. :empty는 공백 텍스트가 있어도 매치되지 않을 수 있다.
:first-child, :last-child, :only-child형제 위치같은 부모의 요소 자식 순서를 센다.
:nth-child(), :nth-of-type()순서모든 요소 형제 기준과 같은 타입 형제 기준의 차이다.
:not(), :is(), :where()조건 조합제외, 선택자 목록 매치, 명시도 0의 조건 묶음이다.
:has()관계 조건내부/주변에 조건을 만족하는 상대 요소가 있는지 검사한다.
:target, :root문서URL 조각과 맞는 요소, 문서 루트다.

헷갈리는 점

  • :is(), :not(), :has()는 인수 중 가장 높은 명시도의 영향을 받는다. :where()와 인수의 명시도는 0이다.
  • nth-child는 1부터 센다. odd는 홀수, even은 짝수, 3n+1은 1, 4, 7번째다.
  • hover는 터치 환경에서 마우스처럼 동작하지 않을 수 있다. 필요한 기능을 hover에만 숨기지 않는다.
