개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • universal-selector — 모든 요소 또는 지정 범위의 모든 후손을 고른다.
  • class-selector — 같은 class를 가진 요소를 고른다.
  • id-selector — 일치하는 id의 요소를 고른다.
  • descendant-selector — 특정 조상 안의 모든 깊이 후손을 선택한다.
  • child-selector — 부모가 정확히 지정한 요소인 자식만 고른다.
  • adjacent-sibling-selector — 같은 부모 안에서 바로 다음에 있는 형제를 고른다.
  • general-sibling-selector — 같은 부모 안에서 뒤쪽의 해당 형제들을 고른다.
  • attribute-selector — 속성 존재나 값 조건으로 요소를 고른다.
