개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • calc() — 서로 다른 길이 등을 계산해 하나의 값으로 만든다.
  • min() — 후보 값 중 계산 결과가 가장 작은 값을 사용한다.
  • max() — 후보 값 중 계산 결과가 가장 큰 값을 사용한다.
  • clamp() — 최솟값과 최댓값 사이에서 선호값을 제한한다.
  • px — CSS 기준 픽셀 길이 단위다.
  • em — 글꼴 크기에 상대적인 단위다.
  • rem — 루트 요소 글꼴 크기에 상대적인 단위다.
  • vw — 뷰포트 너비의 1%에 해당한다.
  • vh — 뷰포트 높이의 1%에 해당한다.
  • dvh — 동적 뷰포트 높이의 1%다.
  • ch — 해당 글꼴의 0 글리프 진행 폭 기준 단위다.
  • percentage — 퍼센트는 속성마다 다른 기준에 대한 비율이다.

키워드와 적용 대상

em, rem글꼴 기준em은 사용 위치의 글꼴 크기 기준, rem은 루트 글꼴 크기 기준이다. font-size의 em은 부모 기준이다.
%속성별 기준width, height, transform 등마다 기준이 다르다.
vw, vh, dvh, svh, lvh뷰포트뷰포트 크기와 동적/작은/큰 뷰포트 기준 단위다.
ch글꼴 너비해당 글꼴의 0 글리프 너비 기준이다. 한국어 글자 수와 같지 않다.
