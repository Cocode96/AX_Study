color는 글자색, background는 요소 뒤에 그리는 배경이다. 이미지 크기와 반복 방식은 각각 별도 속성이다.

개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • color — 텍스트와 currentColor가 참조할 전경색을 지정한다.
  • background-color — 요소 뒤에 칠할 단색 배경을 지정한다.
  • background-image — 배경 이미지 레이어를 지정한다.
  • background-size — 배경 이미지의 크기를 지정한다.
  • background-position — 배경 이미지의 배치 위치를 지정한다.
  • background-repeat — 배경 이미지 반복 방식을 지정한다.
  • background-origin — 배경 이미지 배치 기준 박스를 정한다.
  • background-clip — 배경을 어디까지 칠할지 정한다.
  • background-attachment — 스크롤에 대한 배경의 기준을 지정한다.
  • background — 배경 관련 하위 속성을 한 번에 지정한다.
  • rgb() — RGB 채널과 알파로 색을 만든다.
  • hsl() — 색상 각도, 채도, 명도로 색을 만든다.
  • linear-gradient() — 직선 방향을 따라 색이 변하는 이미지를 만든다.
  • radial-gradient() — 중심에서 바깥으로 색이 변하는 이미지를 만든다.
  • conic-gradient() — 중심 주위의 각도에 따라 색이 변하는 이미지를 만든다.
