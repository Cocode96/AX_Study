CSS / property

background-attachment

스크롤에 대한 배경의 기준을 지정한다.

어디에 쓰나

배경 또는 전경을 바꿀 .target

초깃값: scroll / 상속: 아니오

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { background-attachment: local; }
값 / 문법무엇이 달라지나
local요소 콘텐츠와 함께 스크롤
scroll요소 박스 기준
fixed보통 뷰포트 기준

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

바로 수정하는 예제

background-attachment를 직접 바꾸기

크기가 있는 박스에 적용한다. 배경 이미지는 콘텐츠 높이를 자동으로 만들지 않는다.

안 되거나 헷갈릴 때

작은 고정 예제에서는 차이가 안 보일 수 있다. 스크롤하며 비교하고 모바일에서 실제 동작을 확인한다.

DevTools에서 background-attachment를 검색해 선언이 취소선인지, 최종 계산값이 무엇인지 확인한다. 위의 적용 대상과 부모 조건도 같이 확인한다.
