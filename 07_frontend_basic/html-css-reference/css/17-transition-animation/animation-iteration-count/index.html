CSS / property

animation-iteration-count

애니메이션 반복 횟수를 정한다.

어디에 쓰나

변화시킬 요소 .target

초깃값: 1 / 상속: 아니오

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { animation-iteration-count: infinite; }
값 / 문법무엇이 달라지나
infinite무한 반복
2두 번
1한 번
0재생 안 함

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

바로 수정하는 예제

animation-iteration-count를 직접 바꾸기

전환은 hover/Tab 포커스로, 애니메이션은 재생 체크로 시작한다. 기본은 정지이며 움직임 줄이기 설정을 존중한다.

안 되거나 헷갈릴 때

무한 재생은 필요할 때만 사용하며 정지 방법과 reduced-motion을 제공한다.

DevTools에서 animation-iteration-count를 검색해 선언이 취소선인지, 최종 계산값이 무엇인지 확인한다. 위의 적용 대상과 부모 조건도 같이 확인한다.
