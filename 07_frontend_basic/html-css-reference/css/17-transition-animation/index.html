개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • transition — 속성값이 바뀔 때의 전환을 축약 지정한다.
  • transition-property — 전환할 속성을 정한다.
  • transition-duration — 전환에 걸리는 시간을 정한다.
  • transition-delay — 값이 바뀐 후 전환이 시작될 때까지 기다릴 시간을 정한다.
  • transition-timing-function — 시간에 따른 전환 진행 비율을 정한다.
  • animation — keyframes 기반 애니메이션을 축약 지정한다.
  • animation-name — 사용할 keyframes 이름을 정한다.
  • animation-duration — 애니메이션 한 주기에 걸리는 시간을 정한다.
  • animation-delay — 애니메이션 시작 지연을 정한다.
  • animation-timing-function — 키프레임 구간의 진행 곡선을 정한다.
  • animation-iteration-count — 애니메이션 반복 횟수를 정한다.
  • animation-direction — 각 반복의 진행 방향을 정한다.
  • animation-fill-mode — 재생 전후에 어떤 프레임 스타일을 유지할지 정한다.
  • animation-play-state — 재생 또는 일시정지를 정한다.
  • cubic-bezier() — 전환/애니메이션의 진행 곡선을 제어점으로 정의한다.
  • steps() — 부드러운 변화 대신 일정 단계로 나누어 진행한다.
  • @keyframes — 시간별 애니메이션 상태를 정의한다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준

transition-delay, transition-timing-function전환시작 지연과 시간에 따른 변화 곡선이다.
@keyframes프레임 정의from/to 또는 %로 중간 상태를 작성한다.
animation-name, animation-duration애니메이션사용할 keyframes 이름과 주기다.
animation-iteration-count, animation-direction반복반복 횟수와 진행/왕복 방향이다.
animation-fill-mode전후 상태재생 전후에 keyframe 값을 적용하는 방식을 정한다.
animation-play-state상태running 또는 paused다.
ease, linear, steps(), cubic-bezier()보간시간별 진행 비율을 정한다.
prefers-reduced-motion환경 조건움직임 줄이기 사용자 설정을 감지한다.
