개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • font-family — 글꼴 후보를 순서대로 지정한다.
  • font-size — 글자 크기를 지정한다.
  • font-weight — 글꼴의 굵기를 지정한다.
  • font-style — 기울임 글꼴 스타일을 지정한다.
  • font — 글꼴 하위 속성을 축약해서 지정한다.
  • line-height — 한 줄의 높이 계산을 지정한다.
  • letter-spacing — 글자 사이 추가 간격을 지정한다.
  • word-spacing — 단어 사이 공백 간격을 조절한다.
  • text-align — 블록 안의 인라인 콘텐츠를 정렬한다.
  • text-indent — 첫 줄 들여쓰기를 지정한다.
  • text-decoration — 밑줄/취소선 등의 텍스트 장식을 지정한다.
  • text-transform — 화면 표시에서 대소문자 등을 변환한다.
  • white-space — 공백과 줄바꿈 보존/자동 줄바꿈 방식을 정한다.
  • word-break — 단어/문자 경계의 줄바꿈 규칙을 정한다.
  • overflow-wrap — 긴 문자열이 한 줄에 안 들어갈 때 비상 줄바꿈을 허용한다.
  • text-overflow — 가로로 넘친 텍스트의 끝 표시를 정한다.
  • vertical-align — 인라인 수준 박스나 표 셀의 세로 정렬을 정한다.
  • text-shadow — 글자 형태에 그림자를 그린다.
  • list-style-type — 목록 마커 종류를 지정한다.
  • list-style-position — 목록 마커를 내용 박스 안/밖 어디에 놓을지 정한다.
  • @font-face — 글꼴 파일을 CSS 글꼴 이름에 등록한다.
