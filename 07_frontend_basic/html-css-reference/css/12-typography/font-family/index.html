font-family

글꼴 후보를 순서대로 지정한다.

어디에 쓰나

문단 또는 텍스트를 포함한 요소

초깃값: 사용자 에이전트에 따름 / 상속: 예

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { font-family: Georgia, serif; }
값 / 문법무엇이 달라지나
Georgia, serifGeorgia가 없으면 serif
Consolas, monospace고정폭 글꼴
"Malgun Gothic", sans-serif맑은 고딕 또는 산세리프

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

font-family를 직접 바꾸기

글꼴/줄바꿈은 상속 여부와 사용 가능한 가로폭을 함께 확인한다.

안 되거나 헷갈릴 때

앞 글꼴이 설치/로드되지 않거나 해당 문자가 없으면 대체 글꼴을 사용한다.

DevTools에서 font-family를 검색해 선언이 취소선인지, 최종 계산값이 무엇인지 확인한다. 위의 적용 대상과 부모 조건도 같이 확인한다.
