list-style-position

목록 마커를 내용 박스 안/밖 어디에 놓을지 정한다.

어디에 쓰나

목록을 만드는 ul/ol 또는 list-item

초깃값: outside / 상속: 예

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { list-style-position: inside; }
값 / 문법무엇이 달라지나
inside마커를 첫 줄 인라인 안에
outside마커를 내용 박스 바깥에

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.
