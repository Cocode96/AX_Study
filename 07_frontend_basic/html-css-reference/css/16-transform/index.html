개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • transform — 요소의 시각적 좌표를 이동/회전/확대한다.
  • transform-origin — 회전/확대 등의 기준점을 정한다.
  • translate — transform과 별개로 개별 이동을 지정한다.
  • rotate — 개별 회전을 지정한다.
  • scale — 개별 확대/축소를 지정한다.
  • perspective — 자식의 3D 변환을 바라보는 원근 거리를 정한다.
  • transform-style — 3D 자식의 공간을 유지할지 평면화할지 정한다.
  • backface-visibility — 3D로 회전한 요소의 뒷면을 보일지 정한다.
  • translate() — 요소를 가로/세로로 이동시킨다.
  • rotate() — 2D 평면에서 회전시킨다.
  • scale() — 요소를 시각적으로 확대/축소한다.
  • skew() — 축을 기울여 형태를 왜곡한다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준
translate(), translateX(), translateY()이동변환 기준 박스에 대해 이동한다. %는 보통 자기 크기 기준이다.
rotate(), rotateX(), rotateY()회전2D 또는 3D 축을 기준으로 회전한다.
scale(), scaleX(), scaleY()크기 변환레이아웃 크기 자체와 별개로 시각적으로 확대/축소한다.
skew()기울이기축을 기울여 왜곡한다.
transform-origin변환 중심회전/확대 등의 기준점을 정한다.

transform-style: preserve-3d중첩 3D자식들의 3D 배치를 유지한다.
backface-visibility뒷면회전했을 때 뒷면을 보일지 정한다.
