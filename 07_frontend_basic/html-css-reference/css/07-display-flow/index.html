개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • display — 요소의 바깥 흐름과 내부 자식 배치 방식을 정한다.
  • visibility — 공간을 남긴 채 표시 여부를 제어한다.
  • opacity — 자손을 포함한 요소 결과 전체의 불투명도를 정한다.
  • float — 박스를 한쪽으로 보내 뒤의 인라인 내용이 옆을 흐르게 한다.
  • clear — 앞선 float 옆으로 올라가는 것을 제한한다.
  • cursor — 포인터가 올라왔을 때 커서 모양을 지정한다.
  • pointer-events — 포인터 히트 테스트에 참여할지 정한다.
  • user-select — 사용자가 텍스트를 선택할 수 있는지 정한다.
  • accent-color — 지원하는 기본 폼 컨트롤의 강조 색을 지정한다.
  • appearance — 기본 폼 컨트롤의 플랫폼 모양을 사용할지 정한다.
  • resize — 사용자가 요소 크기를 드래그로 조절할 수 있을지 정한다.
