어디에 쓰나

표시/흐름을 바꿀 요소

초깃값: visible / 상속: 예

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { visibility: hidden; }
값 / 문법무엇이 달라지나
hidden보이지 않지만 공간 유지
visible표시
collapse표 행/열 등에 특수한 접기 동작

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

바로 수정하는 예제

visibility를 직접 바꾸기

inline과 block의 기본 흐름 차이를 먼저 확인한다. float/clear는 앞선 float가 있어야 차이가 난다.

안 되거나 헷갈릴 때

일반 숨김을 opacity:0과 혼동하지 않는다. 자식이 visibility:visible로 다시 보일 수 있다.

DevTools에서 visibility를 검색해 선언이 취소선인지, 최종 계산값이 무엇인지 확인한다. 위의 적용 대상과 부모 조건도 같이 확인한다.
