display

요소의 바깥 흐름과 내부 자식 배치 방식을 정한다.

어디에 쓰나

표시/흐름을 바꿀 요소

초깃값: inline / 상속: 아니오

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { display: block; }
값 / 문법무엇이 달라지나
block새 줄의 블록 박스
inline문장 흐름의 인라인
inline-block인라인 위치와 크기 지정 가능 박스
flex직계 자식 Flex 배치
grid직계 자식 Grid 배치
none레이아웃에서 제거
flow-root독립 블록 서식 문맥

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

바로 수정하는 예제

display를 직접 바꾸기

inline과 block의 기본 흐름 차이를 먼저 확인한다. float/clear는 앞선 float가 있어야 차이가 난다.

안 되거나 헷갈릴 때

초깃값 inline과 div의 브라우저 기본 스타일 block은 다르다. 태그의 의미가 display로 바뀌지는 않는다.

DevTools에서 display를 검색해 선언이 취소선인지, 최종 계산값이 무엇인지 확인한다. 위의 적용 대상과 부모 조건도 같이 확인한다.
