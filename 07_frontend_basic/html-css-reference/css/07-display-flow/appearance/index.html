CSS / property

appearance

기본 폼 컨트롤의 플랫폼 모양을 사용할지 정한다.

어디에 쓰나

실제로 조작할 폼 컨트롤/텍스트

초깃값: none / 상속: 아니오

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { appearance: none; }
값 / 문법무엇이 달라지나
none기본 외형을 제거
auto컨트롤의 자동 외형

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

바로 수정하는 예제

appearance를 직접 바꾸기

이 예제는 표시와 기본 상호작용을 비교한다. 외부 서버로 값을 보내지 않는다.

안 되거나 헷갈릴 때

none 뒤에는 체크/포커스/disabled 등 모든 필요한 상태를 직접 보이게 만들어야 한다. 이 예제에서는 값을 바꾸며 기본 표시 차이만 관찰한다.

DevTools에서 appearance를 검색해 선언이 취소선인지, 최종 계산값이 무엇인지 확인한다. 위의 적용 대상과 부모 조건도 같이 확인한다.
