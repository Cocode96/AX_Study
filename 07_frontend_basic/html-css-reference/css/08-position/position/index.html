CSS / property

position

일반 흐름 참여 여부와 오프셋의 기준 방식을 정한다.

어디에 쓰나

위치를 바꿀 요소

초깃값: static / 상속: 아니오

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { position: absolute; }
값 / 문법무엇이 달라지나
absolute컨테이닝 블록 기준, 일반 흐름에서 제외
relative원래 공간 유지하며 자기 위치에서 이동
static일반 흐름, 오프셋 무시
fixed보통 뷰포트 기준
sticky스크롤 임계값에서 붙음

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

안 되거나 헷갈릴 때

absolute는 가장 가까운 기준 조상을 찾는다. fixed/sticky는 스크롤 가능한 구조에서 따로 확인한다.

DevTools에서 position를 검색해 선언이 취소선인지, 최종 계산값이 무엇인지 확인한다. 위의 적용 대상과 부모 조건도 같이 확인한다.
