position과 기준 좌표

흐름에 참여하는 방식과 오프셋의 기준을 함께 확인한다. absolute의 기준은 바로 위 부모라고 단정할 수 없다.

예제는 독립된 문서로 실행됩니다. 화면 공통 스타일과 섞이지 않으며, 미리보기 안에서 직접 클릭하거나 입력할 수 있습니다. JavaScript는 코드 적용과 너비 조절을 돕습니다.

개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • position — 일반 흐름 참여 여부와 오프셋의 기준 방식을 정한다.
  • top — 위쪽 오프셋 또는 sticky 임계값을 지정한다.
  • right — 오른쪽 오프셋을 지정한다.
  • bottom — 아래쪽 오프셋을 지정한다.
  • left — 왼쪽 오프셋을 지정한다.
  • inset — top/right/bottom/left를 한 번에 지정한다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준
static기본 위치일반 흐름에 배치되고 top 등의 오프셋이 적용되지 않는다.
relative자기 원래 위치공간을 유지한 채 원래 위치에서 시각적으로 이동한다.
absolute컨테이닝 블록일반 흐름에서 빠져 기준 박스에 배치된다.
fixed보통 뷰포트일반적으로 뷰포트 기준이지만 transform 등의 조상이 기준을 바꿀 수 있다.
sticky스크롤 기준흐름을 유지하다 스크롤 임계값에 도달하면 제한 범위 안에 붙는다.
top, right, bottom, left오프셋position과 쓰기 방향에 맞는 위치 값을 지정한다.
inset축약top/right/bottom/left를 한 번에 지정한다.
containing block기준 박스크기와 위치 계산의 기준이다. position과 조상 속성에 따라 정해진다.
