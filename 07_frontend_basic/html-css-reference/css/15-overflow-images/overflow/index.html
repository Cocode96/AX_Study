CSS / property

overflow

박스 밖으로 넘치는 콘텐츠의 표시/스크롤을 정한다.

어디에 쓰나

넘침이 생길 스크롤 부모 .target

초깃값: visible / 상속: 아니오

초깃값은 CSS 명세 기준이다. 브라우저 기본 태그 스타일이나 아래 예제의 준비 스타일과 다를 수 있다.

문법과 값실행/수정안 될 때관련 항목

문법과 값별 차이

선택자 { overflow: auto; }
값 / 문법무엇이 달라지나
auto필요할 때 스크롤
hidden자르지만 프로그램 스크롤 가능
clip자르고 스크롤 컨테이너를 만들지 않음
scroll스크롤 영역 사용
visible밖으로 표시

이 표는 자주 사용하는 값과 비교할 차이를 정리한다. 전체 문법과 세부 지원 버전은 아래 원문 링크에서 확인한다.

overflow를 직접 바꾸기

내부 콘텐츠보다 부모 크기를 작게 지정했다. 해당 영역 안에서 직접 스크롤한다.

안 되거나 헷갈릴 때

레이아웃 크기를 먼저 제한해야 넘침 상황이 생긴다. 축별 값의 계산 상호작용도 확인한다.

DevTools에서 overflow를 검색해 선언이 취소선인지, 최종 계산값이 무엇인지 확인한다. 위의 적용 대상과 부모 조건도 같이 확인한다.
