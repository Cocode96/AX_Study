개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • overflow — 박스 밖으로 넘치는 콘텐츠의 표시/스크롤을 정한다.
  • overflow-x — 가로 방향 넘침을 처리한다.
  • overflow-y — 세로 방향 넘침을 처리한다.
  • overscroll-behavior — 안쪽 스크롤 끝에서 바깥으로 동작이 전달되는 방식을 정한다.
  • scroll-behavior — 앵커/프로그램 스크롤의 이동 방식을 정한다.
  • scroll-snap-type — 스크롤 축과 스냅 강도를 정한다.
  • scroll-padding — 스크롤 컨테이너의 스냅/이동 정렬 여유를 정한다.
  • scroll-snap-align — 아이템의 스냅 정렬 위치를 정한다.
  • scroll-margin — 스크롤 대상의 정렬 경계 바깥 여유를 정한다.
  • object-fit — img/video의 원본 콘텐츠를 자기 박스에 맞추는 방식을 정한다.
  • object-position — 대체 요소 콘텐츠가 박스 안에 놓일 위치를 정한다.
