개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • inline-size — 글 흐름의 인라인 축 크기를 정한다.
  • block-size — 글 흐름의 블록 축 크기를 정한다.
  • margin-inline — 인라인 시작/끝 바깥 여백을 정한다.
  • margin-block — 블록 시작/끝 바깥 여백을 정한다.
  • padding-inline — 인라인 시작/끝 안쪽 여백을 정한다.
  • padding-block — 블록 시작/끝 안쪽 여백을 정한다.
  • border-inline-start — 글 흐름 시작 쪽 테두리를 지정한다.
  • writing-mode — 문장이 가로 또는 세로로 흐르는 방향을 정한다.
  • direction — 기본 텍스트 진행 방향을 지정한다.
  • var() — 사용자 정의 속성값을 참조한다.
  • custom-properties — 반복해서 사용하는 CSS 값을 --이름으로 정의한다.
  • @property — 사용자 정의 속성의 타입/상속/초깃값을 등록한다.

헷갈리는 점

  • --name 값이 존재하더라도 그 값을 넣은 속성 문법이 틀리면 선언은 계산 시점에 무효가 될 수 있다. var의 fallback이 모든 타입 오류를 해결하지는 않는다.
  • 일반 CSS 변수는 C++의 텍스트 매크로와 완전히 같지 않다. 상속과 요소별 캐스케이드의 영향을 받는다.
