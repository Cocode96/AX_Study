개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • img — 콘텐츠 이미지를 삽입한다.
  • picture — 조건에 따라 다른 이미지 소스를 선택한다.
  • figure — 본문에서 독립적으로 참조 가능한 그림/코드 등의 단위를 묶는다.
  • figcaption — figure의 캡션을 제공한다.
  • iframe — 독립적인 중첩 HTML 문서를 삽입한다.
  • svg — 요소로 구성되는 벡터 그래픽을 삽입한다.
  • canvas — 스크립트가 그릴 비트맵 표면을 만든다.
  • audio — 음성 재생 요소를 제공한다.
  • video — 영상 재생 요소를 제공한다.
  • source — picture 또는 audio/video에 조건별 자원 후보를 제공한다.
  • track — video/audio에 자막 등의 시간 기반 텍스트를 연결한다.
  • src — 가져올 이미지/스크립트/문서 등의 자원 주소다.
  • alt — 이미지의 대체 텍스트를 제공한다.
  • srcset — 이미지 소스의 해상도/너비 후보를 제공한다.
  • sizes — 반응형 이미지의 예상 표시 너비를 브라우저에 알린다.
  • loading — 화면 밖 자원의 로딩 시점을 제안한다.

헷갈리는 점

  • video에는 controls와 필요한 자막을 제공한다. 예: <video controls><source src="clip.mp4" type="video/mp4"><track kind="captions" src="ko.vtt" srclang="ko" label="한국어"></video>. 실제 미디어 파일은 별도로 필요하다.
  • srcset의 480w와 960w는 이미지 파일의 실제 픽셀 너비다. sizes는 이미지가 배치될 너비 조건이다.
  • object-fit은 img/video 콘텐츠의 박스 내부 맞춤 방식이다. CSS 배경에는 background-size를 사용한다.
