개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • details — 기본 펼침/접힘 UI를 만든다.
  • summary — details의 열기/닫기 제목을 제공한다.
  • dialog — 브라우저가 관리하는 모달/비모달 대화상자를 만든다.
  • progress — 진행 중인 작업의 완료 정도를 나타낸다.
  • meter — 알려진 범위 안의 측정값을 나타낸다.
  • template — 당장 렌더링하지 않고 나중에 복제할 HTML을 보관한다.
  • dir — 콘텐츠의 글 진행 방향을 지정한다.
  • hidden — 요소가 현재 문서에서 표시되어야 하지 않음을 지정한다.
  • inert — 요소 하위의 사용자 상호작용과 포커스 등을 제한한다.
  • tabindex — 요소의 포커스 가능 여부와 Tab 순서를 조절한다.
  • aria-label — 보조 기술이 읽을 접근 가능한 이름을 제공한다.
  • aria-describedby — 요소에 대한 추가 설명을 다른 id의 내용과 연결한다.
  • aria-labelledby — 다른 요소의 텍스트를 접근 가능한 이름으로 연결한다.
  • aria-live — 동적으로 바뀌는 영역을 보조 기술에 알린다.
  • data-* — 앱 전용 데이터를 요소에 저장한다.
  • popover — 요소를 브라우저의 팝오버로 표시하게 한다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준
details, summary, open펼침 영역summary를 눌러 상세 내용을 열고 닫는다.
dialog, showModal()대화상자모달로 열면 바깥 콘텐츠의 상호작용을 제한하고 포커스를 관리한다.
popover, popovertarget팝오버연결된 버튼으로 보조 UI를 토글한다. 기본 auto는 바깥 클릭 등으로 닫힌다.
aria-label, aria-labelledby접근 가능한 이름화면에 드러나지 않는 이름이나 제목 요소 연결에 사용한다.
aria-describedby추가 설명입력 조건 등의 설명 요소를 연결한다.
aria-live상태 안내동적으로 바뀐 내용을 보조 기술에 알릴 때 사용한다.
tabindex포커스0은 일반 Tab 순서에 포함, -1은 보통 스크립트로 포커스할 때 사용한다.
hidden, inert표시/상호작용hidden은 렌더링 제외, inert는 하위 상호작용과 포커스를 제한한다.
progress, meter상태 값작업 진행률과 알려진 범위 안의 측정값이다.
data-*사용자 정의 데이터요소에 앱 전용 데이터를 붙인다. 단독으로 동작하지 않는다.
