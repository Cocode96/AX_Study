개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • header — 페이지 또는 구획의 머리말을 담는다.
  • nav — 주요 탐색 링크를 묶는다.
  • main — 문서의 지배적인 주요 콘텐츠를 담는다.
  • section — 하나의 주제를 가진 문서 구획을 만든다.
  • article — 독립적으로 배포하거나 재사용할 수 있는 콘텐츠 단위다.
  • aside — 본문과 관련 있지만 부수적인 정보를 담는다.
  • footer — 페이지 또는 가까운 구획의 꼬리말을 담는다.
  • div — 별도 의미 없이 흐름 콘텐츠를 묶는다.
  • span — 문장 안의 일부를 의미 없는 인라인 묶음으로 감싼다.
  • h1-h6 — 문서 제목의 논리적 계층을 표현한다.
  • address — 가까운 article 또는 문서의 연락처 정보를 담는다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준
header, footer페이지 또는 구획머리말과 꼬리말이다. 고정 위치를 뜻하지 않는다.
nav주요 탐색 영역주요 페이지 또는 구획 이동 링크를 묶는다.
main문서 주요 콘텐츠일반적인 문서에서는 표시되는 main을 하나 둔다.
section주제별 구획보통 제목과 함께 하나의 주제를 묶는다.
article독립 콘텐츠게시글, 기사처럼 독립적으로 재사용할 단위다.
aside보조 콘텐츠관련 링크, 부가 설명처럼 본문에 부수적인 내용이다.
div, span일반 묶음특별한 의미 없이 묶는다. 기본 div는 block, span은 inline이다.
h1 ~ h6제목 단계문서의 논리적 계층을 표시한다. 글자 크기 때문에 단계를 고르지 않는다.
