예제는 독립된 문서로 실행됩니다. 화면 공통 스타일과 섞이지 않으며, 미리보기 안에서 직접 클릭하거나 입력할 수 있습니다. JavaScript는 코드 적용과 너비 조절을 돕습니다.

개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • form — 입력 필드를 묶어 이름/값 데이터를 제출한다.
  • label — 입력 컨트롤의 이름과 클릭 대상을 연결한다.
  • input — type에 따라 한 줄 입력/선택/파일 등의 컨트롤을 만든다.
  • button — 사용자 조작 버튼을 만든다.
  • textarea — 여러 줄 텍스트 입력 컨트롤을 만든다.
  • select — 선택 목록에서 값을 고르게 한다.
  • option — select/datalist의 선택 후보를 만든다.
  • optgroup — select의 관련 선택지를 그룹으로 묶는다.
  • fieldset — 관련 입력을 하나의 그룹으로 묶는다.
  • legend — fieldset 그룹의 제목을 제공한다.
  • datalist — 자유 입력에 선택 가능한 추천값을 제공한다.
  • output — 계산 또는 사용자 동작의 결과를 나타낸다.
  • for — label을 특정 입력 id와 연결한다.
  • name — 폼 데이터의 필드 이름을 지정한다.
  • value — 컨트롤의 값 또는 전송 값을 정한다.
  • type — input 또는 button의 동작 종류를 정한다.
  • required — 지원 입력이 비어 있으면 유효하지 않게 만든다.
  • disabled — 지원 컨트롤을 조작 불가 상태로 만든다.
  • readonly — 지원 텍스트 입력 등을 편집 불가로 만든다.
  • checked — checkbox/radio의 초기 선택 상태를 지정한다.
  • placeholder — 입력이 비어 있을 때 짧은 힌트를 보여 준다.
  • pattern — 지원 텍스트 입력의 값 전체에 정규식 조건을 적용한다.
  • min — 숫자/날짜 등의 허용 최솟값을 정한다.
  • max — 숫자/날짜 등의 허용 최댓값을 정한다.
  • step — 수치 입력의 유효한 간격을 정한다.
  • maxlength — 입력 문자열의 최대 길이를 제한한다.
  • autocomplete — 브라우저 자동 완성의 목적을 설명한다.
  • inputmode — 가상 키보드에 입력 종류 힌트를 준다.
  • method — form 데이터 전송 방식을 정한다.
  • action — form 제출을 처리할 URL을 지정한다.
  • enctype — POST 폼 데이터의 인코딩 방식을 정한다.

키워드어디에 쓰나역할 / 기준
form action, method폼전송 대상과 GET/POST 방식을 정한다.
label for, input id입력 연결for와 id가 일치하면 라벨 클릭으로 입력에 접근한다.
name, value전송 데이터필드 이름과 값이다. id만으로 전송 이름이 생기지 않는다.

checkbox, radio선택 입력checkbox는 독립 선택, 같은 name의 radio는 그룹 안의 단일 선택이다.
required, min, max, step, pattern입력 조건빈 값, 수 범위, 간격, 문자열 패턴 등을 검사한다.
select, option, optgroup선택 목록선택 가능한 값과 그룹이다.

fieldset, legend관련 입력 묶음라디오 그룹처럼 관련된 입력과 그룹 제목을 묶는다.
disabled, readonly상태disabled는 보통 전송에서 빠지고, readonly는 지원 입력에서 읽기 전용이며 전송된다.
button type버튼submit, reset, button을 명시해 의도하지 않은 전송을 막는다.
autocomplete, inputmode입력 보조자동 완성 목적과 가상 키보드 힌트다. 검증 규칙은 아니다.

헷갈리는 점

  • GET은 보통 조회에 사용하며 입력값이 URL 쿼리에 들어간다. POST는 요청 본문을 사용한다. POST 자체가 암호화를 뜻하지는 않는다.
  • 체크되지 않은 checkbox와 disabled 입력은 보통 FormData에 들어가지 않는다.
  • 브라우저 검증은 입력 도움이다. 실제 서비스에서는 서버에서도 검증해야 한다. 파일 전송 폼에는 enctype="multipart/form-data"가 필요하다.
