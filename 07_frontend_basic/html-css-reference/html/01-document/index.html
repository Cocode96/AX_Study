HTML은 콘텐츠의 의미와 부모/자식 구조를 표현한다. CSS는 그 구조가 화면에 보이는 방식을 정한다.

개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • html — 문서 루트 요소이며 문서 언어를 함께 지정한다.
  • head — 문서 제목과 인코딩, 스타일 연결 등 메타데이터를 담는다.
  • body — 문서에서 사용자에게 제공할 콘텐츠를 담는다.
  • title — 문서의 이름을 브라우저 탭과 북마크 등에 제공한다.
  • meta — 인코딩, 뷰포트, 설명 등의 문서 메타데이터를 지정한다.
  • link — 외부 리소스와 문서의 관계를 선언한다.
  • style — HTML 문서 안에 CSS 규칙을 작성한다.
  • script — 스크립트를 실행하거나 외부 스크립트를 연결한다.
  • noscript — 스크립트가 비활성인 환경에서 대체 내용을 제공한다.
  • id — 문서 안에서 고유한 식별자를 지정한다.
  • class — 여러 요소를 재사용 가능한 이름으로 묶는다.
  • lang — 문서/일부 콘텐츠의 언어를 알린다.
  • style-attribute — 요소 하나에 인라인 CSS 선언을 적용한다.

헷갈리는 점

  • 태그 이름과 속성 이름은 다른 역할이다. class="card"에서 class는 속성, card는 값이다.
  • img, input, meta, link, br 같은 void 요소는 닫는 태그를 쓰지 않는다.
  • 외부 파일 연결 예: <link rel="stylesheet" href="./style.css">. 이 자료는 공통 화면 CSS만 assets에 공유한다.
