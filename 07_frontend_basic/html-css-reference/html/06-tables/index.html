표와 데이터 구조

표는 행과 열 사이의 관계를 표현한다. 화면 전체 배치를 위해 table을 사용하지 않는다.

키워드 표실행 예제헷갈리는 점

예제는 독립된 문서로 실행됩니다. 화면 공통 스타일과 섞이지 않으며, 미리보기 안에서 직접 클릭하거나 입력할 수 있습니다. JavaScript는 코드 적용과 너비 조절을 돕습니다.

개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • table — 행과 열 사이의 데이터 관계를 표현한다.
  • caption — 표의 제목/설명을 제공한다.
  • thead — 표의 열 제목 행들을 묶는다.
  • tbody — 표의 본문 행들을 묶는다.
  • tfoot — 표의 합계나 요약 행을 묶는다.
  • tr — 표의 한 행을 만든다.
  • th — 행/열 제목 셀을 만든다.
  • td — 표의 데이터 셀을 만든다.
