개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • p — 하나의 문단을 표현한다.
  • br — 문장 안에서 의미 있는 줄바꿈을 만든다.
  • hr — 문단 수준의 주제 전환을 나타낸다.
  • strong — 내용의 중요성이나 심각성을 표시한다.
  • em — 문장의 강세 강조를 표현한다.
  • b — 추가적인 중요성 없이 주의를 끄는 텍스트를 표시한다.
  • i — 다른 목소리, 기술 용어 등 일반 본문과 구분되는 텍스트를 표시한다.
  • mark — 현재 문맥에서 관련성이 높은 부분을 강조 표시한다.
  • small — 저작권/주석 등 부가 문구를 표현한다.
  • blockquote — 다른 출처의 긴 블록 인용을 나타낸다.
  • q — 문장 안의 짧은 인용을 나타낸다.
  • cite — 책, 글, 작품 등의 제목을 나타낸다.
  • pre — 공백과 줄바꿈을 보존하는 미리 서식 지정된 텍스트다.
  • code — 프로그램 코드 또는 코드 조각을 표현한다.
  • kbd — 사용자 키보드 입력을 나타낸다.
  • samp — 프로그램 출력 예시를 나타낸다.
  • abbr — 약어와 풀이를 연결한다.
  • time — 사람이 읽는 시간과 기계가 읽는 날짜/시간을 연결한다.
  • sub — 아래 첨자를 표현한다.
  • sup — 위 첨자를 표현한다.
  • del — 문서에서 삭제된 부분을 표시한다.
  • ins — 문서에 추가된 부분을 표시한다.
  • ul — 순서가 중요하지 않은 목록을 만든다.
  • ol — 순서가 중요한 목록을 만든다.
  • li — ul/ol/menu의 목록 항목을 나타낸다.
  • dl — 용어와 설명의 대응 목록을 만든다.
  • dt — dl 안의 용어나 이름을 나타낸다.
  • dd — dl 안의 용어에 대한 설명이나 값을 나타낸다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준
p, br, hr본문문단, 문장 내 줄바꿈, 주제 전환을 각각 나타낸다.
strong, em텍스트중요성과 강세를 나타낸다.
b, i, u, s텍스트주의를 끄는 글, 다른 목소리, 주석 표시, 더 이상 정확하지 않은 내용을 구분한다.
mark, small텍스트맥락상 강조 표시와 부가 문구다.
blockquote, q, cite인용블록 인용, 짧은 인용, 작품 제목이다.
pre, code, kbd, samp기술 내용공백 보존, 코드, 사용자 입력, 프로그램 출력을 표현한다.
ul, ol, li목록순서 없는/있는 목록과 항목이다.
dl, dt, dd용어 설명용어와 설명을 대응시킨다.
sub, sup, abbr, time특수 텍스트아래/위 첨자, 약어, 기계가 읽을 날짜 등을 표현한다.
&lt;, &gt;, &amp;문자 참조태그로 해석될 문자나 &를 텍스트로 표시한다.
