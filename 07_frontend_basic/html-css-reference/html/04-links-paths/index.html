링크와 파일 경로

href는 이동할 목적지, src는 가져올 자원 주소다. 상대 경로는 기준 파일 위치부터 계산한다.

키워드 표실행 예제헷갈리는 점

예제는 독립된 문서로 실행됩니다. 화면 공통 스타일과 섞이지 않으며, 미리보기 안에서 직접 클릭하거나 입력할 수 있습니다. JavaScript는 코드 적용과 너비 조절을 돕습니다.

개별 키워드 백과사전

한 항목만 찾아 문법, 값, 예제와 실패 조건을 확인한다.

  • a — 목적지로 이동하는 하이퍼링크를 만든다.
  • href — 이동할 목적지 또는 연결 리소스의 주소를 지정한다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준
a href링크다른 문서, 주소, 문서 내부의 #id로 이동한다.
./, ../상대 경로현재 폴더, 한 단계 위 폴더다.
/images/a.png루트 경로웹에서는 사이트 루트 기준이다. 파일을 직접 열 때는 의미가 달라진다.
https://절대 URL프로토콜과 호스트를 포함하는 주소다.
target, rel링크 속성새 탭 등 탐색 위치와 문서 관계를 지정한다.
download다운로드 힌트같은 출처 등의 제약을 받으며 파일 저장을 제안한다.
mailto:, tel:외부 처리 링크메일/전화 앱으로 전달한다.
url(...)CSS 파일외부 CSS의 상대 이미지 경로는 HTML이 아닌 CSS 파일 위치 기준이다.
