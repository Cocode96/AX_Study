키워드어디에 쓰나역할 / 기준
중앙 정렬Grid / Flexbox부모의 display와 축 정렬을 먼저 선택한다.
반응형 카드 목록Gridauto-fit, minmax, gap을 조합한다.
이미지 위 버튼position움직이는 이미지 트랙 바깥의 relative 래퍼에 버튼을 둔다.
고정 비율 썸네일aspect-ratio / object-fit비율과 이미지 맞춤을 분리한다.
말줄임 제목min-width / overflowFlex/Grid 아이템 최소 너비도 확인한다.
CSS 토글 패널:checked / 형제 선택자상태 input과 뒤쪽 패널의 실제 형제 관계를 맞춘다.
