키워드 표실행 예제헷갈리는 점

예제는 독립된 문서로 실행됩니다. 화면 공통 스타일과 섞이지 않으며, 미리보기 안에서 직접 클릭하거나 입력할 수 있습니다. JavaScript는 코드 적용과 너비 조절을 돕습니다.

키워드와 적용 대상

키워드어디에 쓰나역할 / 기준
CSS가 안 먹음Elements / Styles선택자 매치, 파일 로드, 구문 오류, 덮어쓴 선언을 확인한다.
정렬이 안 됨부모 display부모가 Flex/Grid인지, 축 방향과 남는 공간이 있는지 확인한다.
absolute 위치가 이상함기준 조상가까운 positioned 조상 또는 transform 등의 기준 변화를 찾는다.
z-index가 안 먹음쌓임 맥락조상 z-index, opacity, transform 경계를 확인한다.
페이지가 가로로 넘침실제 너비고정 width, min-width, 긴 단어, padding, 100vw를 확인한다.
이미지가 안 보임Network / 경로src와 CSS url의 기준 파일, 대소문자, 응답 상태를 확인한다.
sticky가 안 붙음스크롤 조상overflow, top, 컨테이너 높이와 스크롤 여유를 확인한다.
체크 상태가 안 적용됨DOM 형제 관계input:checked + 대상의 순서와 부모가 맞는지 본다.
Computed최종 계산값최종값과 해당 값이 어디에서 왔는지 확인한다.
박스 모델 패널실제 크기content, padding, border, margin의 실제 값을 확인한다.

헷갈리는 점

  • DevTools에서 선택한 DOM 요소는 Console의 $0으로 참조할 수 있다. $0은 HTML에 쓰는 문법이 아니다.
  • 브라우저에서 바꾼 Styles 값은 원본 파일에 자동 저장되지 않는다. 확인한 수정은 HTML/CSS 파일에 반영한다.
